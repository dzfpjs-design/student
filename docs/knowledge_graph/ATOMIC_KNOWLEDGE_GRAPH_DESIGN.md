# 原子知识图谱设计与构建门禁

## 1. 先纠正原来的错误

原目录中的约 300 项大多是章节或主题，例如“二次函数”“圆”“阅读理解”。它们适合导航，不适合记录孩子掌握度。视频数量也不能直接决定知识点数量：多个课时可能讲同一个能力，一个课时也可能包含多个可独立诊断的能力。

视频转录的正确角色是：提供学习目标证据、讲解片段、例题、评测提示和错因线索。转录不是本体，不能通过寻找“理解、掌握、计算”等动词直接自由生成正式知识点。

## 2. 原子知识点的操作性定义

一个原子知识点必须同时满足：

1. 只有一个可观察动作，例如识别、判断、计算、解释、概括、实验或写作。
2. 有边界明确的知识成分，脱离当前例题后仍能再次测量。
3. 可以单独出题诊断，错误时可以单独补救，掌握度可以单独更新。
4. 有基础识别、独立应用、迁移或延迟复测三层标准。
5. 至少关联一条本地逐字证据；课标对齐也必须能回到官方页码和逐字短引。

例：

| 层级 | 示例 | 是否用于掌握度 |
|---|---|---|
| 学科领域 | 数与代数 | 否 |
| 单元主题 | 二次函数 | 否 |
| 综合能力 | 掌握二次函数图像和性质 | 否，仍需拆分 |
| 原子能力 | 判断系数 `a` 的符号对应的抛物线开口方向 | 是 |
| 原子能力 | 根据解析式确定抛物线对称轴 | 是 |
| 原子能力 | 解释 `|a|` 变化与抛物线开口宽窄的关系 | 是 |
| 题目实例 | 给定 `y=-2x²+3` 判断开口方向 | 否，是评测证据 |

语文中也要区分课文内容和迁移能力。例如《观潮》是教材内容节点；“找出文中描写潮水形态的语句”是课文内任务；“依据时空顺序概括写景文章的主要内容”是可迁移原子能力。课文内事实可作为事实型原子项，但不得和通用阅读能力合并成一个掌握度。

## 3. 图谱节点

正式图谱包含以下不同职责的节点：

- `standard_requirement`：国家课标内容要求、学业要求和学业质量要求。
- `domain/topic/unit/lesson`：学科、领域、单元和课程内容结构，只负责组织。
- `atomic_definition`：可独立诊断的知识、技能或策略，是孩子掌握度的唯一主要目标。
- `misconception`：具体可观察错误，不是对孩子人格或能力的评价。
- `assessment_blueprint/exercise`：题型族与具体题目，负责测量原子项。
- `explanation/resource_segment`：教材页、转录片段和讲解视频，负责教学与追溯。
- `student_evidence/mastery_state`：孩子作答证据和随时间更新的掌握状态。

单词、汉字、固定搭配和课文内事实数量很大，应作为事实或语言原子项进入专门子图，不能被 300 个宽泛主题吞掉。

## 4. 图谱关系

关系必须有明确语义，禁止用一个模糊的 `related_to` 代替教学关系：

| 关系 | 语义与约束 |
|---|---|
| `part_of` | 原子项属于概念、单元或领域；不是前置关系 |
| `aligned_to` | 原子项落实某条课标要求，必须有官方页码和逐字依据 |
| `prerequisite_of` | 掌握源项是学习目标项的认知必要条件；方向为前置到后继，必须无环 |
| `enables` | 源项会提高后项成功率，但不是严格必要条件 |
| `representation_of` | 符号、图像、表格、语言或实验表征之间的对应 |
| `contrasts_with` | 容易混淆且需要辨析的概念或方法 |
| `transfers_to` | 同一能力在新材料、新情境或更高复杂度中的迁移 |
| `misconception_of` | 具体错误表现指向某个原子项 |
| `assessed_by` | 原子项由题型族或具体任务测量 |
| `remediated_by` | 某讲解、例题或活动用于修复该原子项 |
| `evidenced_by` | 定义或关系由本地转录、教材页或课标页支撑 |
| `co_taught_with` | 同课共现，仅用于资源组织，绝不能推断为前置关系 |

跨课前置关系分两阶段建立：先从课标明确表述、定义依赖和经审核的学科规则生成候选；再对完整学科子图做无环检查和教研抽审。课程先后顺序只能产生 `co_taught_with` 或弱序列提示，不能自动产生 `prerequisite_of`。

## 5. 三层构建流水线

### 5.1 结构层

从苏 e 优课元数据库读取学段、年级、学科、教材版本、册次、单元路径和章节标题。原先 3916 份资源缺少年级或学科的导入问题已经修复。课程先合并为稳定的 lesson/topic，不按“一个视频一个知识点”处理。

### 5.2 模型草案层

同一课或单元最多四份资源组成一批。每个资源只选最多五个高价值片段，每段最多 900 字，并附相关课标候选页。模型必须输出严格 JSON：原子类型、单动作、知识成分、能力边界、三层掌握标准、三层诊断蓝图、具体易错点、概念标签、逐字转录证据、逐字课标对齐和带证据的关系。

模型输出经过强校验：字段白名单、动作唯一、主题词拦截、课堂话语拦截、逐字证据校验、批内资源全覆盖、三层诊断完整、关系端点校验和前置无环校验。任何一项失败则整批失败并可重试，不允许部分脏数据进入图谱。

### 5.3 审核与发布层

模型结果只写入 `kg_atomic_definition_draft`、`kg_atomic_draft_evidence` 和关系候选表，状态为 `unreviewed`。只有审核通过并经过重复合并、课标覆盖和关系无环门禁后，才投影为正式 `kg_node`、原子档案和资源映射。孩子计划、错题诊断和掌握度算法只消费已批准原子项。

## 6. 当前真实盘点

截至 2026-08-28：

- 已索引 3971 份课程资源、34482 个本地转录片段；原始视频仍保存在外部媒体目录。
- 目标年级四年级和初三的语文、数学、英语、物理、化学共有 765 个资源槽位。
- 按相同课程合并后形成 350 个可恢复模型批次，而不是 765 个或 300 个知识点。
- 350/350 批次都带有学段、学科领域和课程关键词召回的官方课标候选页。
- 批次平均约 1.26 万字，最大约 2.55 万字；原始整段转录不会直接上传。
- 严格协议、持久化闭环和同义合并候选已有 16 项测试，模型草案目前仍为 0；当前命令环境未注入模型凭据，所以尚未真实调用千问生成草案。

现有正则抽取曾产生 2560 个候选签名，但人工抽样仍有明显 ASR 串句和教师话语污染，因此该批候选已明确废弃，不能作为知识图谱规模或完成度。

## 7. 质量门禁

正式发布不能以知识点数量为唯一指标。每个目标学科至少分层抽审 100 项，并同时达到：

- 逐字证据可追溯率 100%。
- 单动作和可独立诊断率不低于 95%。
- 主题标题、教师话语、题目答案误入率为 0。
- 抽样原子定义准确率不低于 90%，未达到则调整提示或分科规则后整批重建。
- 重复合并后的同义重复率低于 10%。
- 已批准 `prerequisite_of` 无自环、无环路，且每条有认知依赖依据。
- 目标课程资源至少 95% 能映射到一个已批准原子项；未覆盖资源进入缺口队列，不能凭空补点。
- 每个已批准原子项至少有一种诊断题型和一种补救资源，才能被学习计划消费。

规模的合理预期是：目标八个年级学科组合最终会产生数千个稳定原子定义和更多证据映射；加上英语词汇、汉字、课文事实、题目与错题后，子图节点可达到万级。但最终数量必须由去重后的可测定义决定，而不是为了超过 300 人为切碎。

## 8. 南京教材页级证据

- 家庭自有的 74 本南京小学四至六年级、初中一至三年级教材作为本地受限证据，原始 PDF 和页图不上传、不进应用安装包。
- 扫描版 PDF 用 RapidOCR 按页识别，保留 `PDF 相对路径 + 页码 + OCR 置信度 + 复核标记`；公式、手写和复杂版式页默认需要二次校验。
- 先用年级、学科、学期和本地词法证据将教材页与视频原子草案对齐；候选关系必须引用 OCR 文本中连续的原文片段。
- 本地匹配只写入 `kg_atomic_textbook_alignment`，保持 `unreviewed`并标为 `mention`，不直接改写正式原子证据。只有定义、例题、练习或总结的完整上下文经模型或人工确认后，才能升级证据角色。仅对歧义候选和教材未覆盖章节调用千问进行验证或补提取。

## 9. 视频与安装包边界

240GB 视频不打进应用安装包。知识包只保存：原子定义、关系、课标短引、转录证据片段、视频文件相对路径和可选时间范围。家庭电脑检测到外部媒体目录时可播放对应视频；媒体缺失时图谱、诊断和讲解仍可工作，并提示该讲解资产暂不可用。发布时分别提供小型应用安装包、版本化知识包和可选外部媒体包。
