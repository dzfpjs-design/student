# 四年级至初三教材与原子草案来源盘点

核对日期：2026-11-15。此盘点记录本机现存文件和数据库关系，供逐册审校使用。

## 文件

- [教材逐册盘点](教材逐册盘点.csv)包含每册文件、年级、学期、版别标签、PDF 页数、OCR 覆盖、前八页版次线索与证据路径。
- [新增教材对应盘点](新增教材对应盘点.csv)记录用户新增 48 册与原 74 册的对应关系、清单所述版本和重叠页抽样差异。
- [草案直接来源覆盖](草案直接来源覆盖.csv)按资源原有年级、学科和来源库统计与草案有直接证据关联的资源和草案数量。

## 使用边界

- 页数只记录现有 PDF 页数，不能独立判定完整性。48 或 49 页的 44 册均已依据原书目录列出的正文页码超过 PDF 总页数，确认不完整，表中保存了对应目录 OCR、末页 OCR 和摘录；其余各册完整性待逐册核对。
- 版别标签来自文件名和目录元数据；版次线索是未经人工逐页校对的 OCR 摘录，当前是否为南京学校实用版本仍需通过教材版权页和官方目录核实。前八页没检出不代表教材没有版权页或没有版次。
- 来源覆盖表仅包括 `kg_atomic_draft_evidence` 直接连到有明确年级标签的资源。思维导图等未使用相同年级标签的资料、跨学段资料、教材页词面待审对齐与其他候选不包含在此表。未列出不等于此学科完全没有草案。
- 同一草案可关联多个资料或来源库，行内去重、跨行不可直接相加。资源数和草案数不代表内容覆盖率、经过审核的知识点数或现行教材符合率。
- 构建库草案与客户端运行库是不同层次。待审草案不能当作完成审核或已经同步到 Windows 的知识。

## 统计

- 四至九年级教材文件共 74 册。
- 文件页数为 48 或 49 的共 44 册，需优先对照目录。
- 前八页 OCR 抽取到版次、审定或 ISBN 线索的共 41 册。
- 草案构建库只读核查时共 151,108 条原子草案，状态均为 unreviewed。

数据来源：`~/.home-study-companion/knowledge-build/textbooks/textbook-metadata.db`、其 `ocr` 页面和 `~/.home-study-companion/knowledge-build/atomic-full-v6.db`。

## 新增教材对应情况

- 用户新增小学教材 12 册、初中教材 36 册。原盘点中 30 册已确认不完整的教材有同年级、学科、册次的新增文件。其中一册五年级语文下册实为四年级下册，纠正后有 29 册按文件名匹配的缺页册次，再加上纠正后的四年级语文下册，共 30 册按实际年级、学科与册次对应。版本一致及完整性仍须逐册核对。
- 重叠页按 PDF 第 4、10、20、30、40、47 页生成 100×140 灰度缩略图，记录平均像素差，只用于查找疑似同版和明显差异。图像接近并不能证明同版本或全部页面一致，裁切、版本、标注和扫描质量均可影响结果。
- 新增清单把初中化学标为沪教版，原档案为人教版。新增清单将部分初中数学、物理、英语标为旧版，是否适用于南京现行教学需继续核对。小学新增文件中的两份标为五年级语文的文件经封面确认实际是四年级上下册。
- 新增教材仍保存在用户给定的 Downloads 原位置，暂未导入原子构建库或替换原文件。

- 两份新增语文文件名存在错标。`语文_五年级_上册.pdf` 与 `语文_五年级_下册.pdf` 的文字封面均显示四年级。上册与既有四年级上册的 138 个重叠页缩略图均一致；下册与既有四年级下册的前 49 页有大量相近页面，同时有明显差异页面，需核对具体版本。两份文件均不能作为五年级语文教材。

本轮为原来按文件名对应缺页教材的 30 册均定位目录和末页线索，29 册取得版权页或封底 ISBN 线索。八年级历史下册仍需人工确认版权页。与原档案比较的“真实匹配”仅指年级、学科、上下册一致；出版社、版本及完整性尚有未核验项目，特别是九年级下册化学两个文件出版社不同。
