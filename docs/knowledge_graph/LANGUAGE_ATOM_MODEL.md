# 语言原子点：老师可诊断的最小单元

“英语词汇”“生词理解”“生字”都不是原子点。原子必须对应一次可观察表现、一个错误归因和一次可复测动作。

| 学科 | 同一教材词/字的原子拆分 |
|---|---|
| 英语单词/词组 | 词形与读音识别、语境义、搭配或句型运用 |
| 语文汉字 | 字音认读、字形书写、语境义与组词 |
| 语文词语 | 词义辨析、搭配、句中理解/运用 |

教材 OCR 页只是来源证据，不自动证明该词是本课生词或孩子已掌握。`TextbookLanguageAtomProjector` 接收本机词表/课本焦点词，先确认该词确实出现在该页，再创建上述原子并记录页码。后续可由本地 OCR 词表提取器提供焦点词；没有教材词表时系统只显示“待补词表”，不把所有 OCR 字符误判为教学目标。

## 规范档案与关系

`kg_language_lexeme` 保存词字档案：教材版本/册次、单元、课文和页码由关联的 `kg_resource`/`kg_document_page` 提供；英语记录词性、义项、搭配、易混词、拼读/音标，汉字记录读音、多音字、部首、结构、笔顺引用、组词与易错字形。`kg_language_lexeme_page` 保存 OCR 页面的逐字证据。词字条目是 `unit`，以 `contains` 关联识读/字形/语境义/运用等 `knowledge_point`；每个原子再用 `explains` 关联本页片段，因此可以接收已有错题证据、进入掌握度和间隔复习计划。

录入边界：用户教材 OCR 可提供页面证据和焦点词，但不会从公开视频转录推断教材词表；结构化词表缺失时只生成候选清单与缺口提示。
