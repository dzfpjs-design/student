# 高拍仪多帧候选：现状与验收边界

状态：`partial`。早期图像拼接候选保持停用；新的 `document_ocr_preview` 已接通固定原帧的 OCR 文字与 ORB 配准多帧草稿，完整功能仍需真实用户与设备验收。逐帧采集和 OCR 使用原始单帧，跨帧累计的是有来源的文字观测，不拼接像素、不补写未知区域。

## 当前本机文字草稿（2026-11-23，partial）

`document_ocr_preview` 绑定孩子、会话、阶段、设备租约、监控代次和页面 token，以固定原帧及来源摘要保留每条 OCR 读值的位置。可可靠配准时累计草稿，并区分当前观测、历史观测和冲突；订正后的不同读值保留各自来源，OCR 漏识别不证明擦除。候选不授予正式作业、错题、讲题或报告证据权限。

几何配准与部分文字一致支持坐标映射，不证明同版式实体纸张的身份；文字差异也不等于物理翻页。草稿最多保留 32 个实际来源、300 行；达到上限时保留既有累计稿与本次单帧读值。ORB 配准特征只在内存中保存，空闲 5 分钟释放；只有完成作用域复核并成功提交的有效配准才续空闲时间，固定锚和描述子不随合并漂移。隐私删除清理相关内存特征，换作用域隔离旧特征；重启或过期后另建锚，已保存的旧草稿仍可读取。

本轮未复现先前黑画面，原因仍未查明。真实手部遮挡、连续书写、订正和翻页的完整现场流程待实测；本机代码、合成像素、OCR 或落库测试不能替代这项验收。

## 早期图像拼接候选的拒绝边界

早期 `document_ocr_candidate` 图像拼接路径的候选 API、OCR 工作流与底层正式证据写入仍拒绝新候选。这与已接通的 `document_ocr_preview` 文字草稿是不同路径。历史上若已存在 `document_ocr_candidate`，新建及修改作业、任务完成和相关操作重放不能将它当成有效 OCR 证据；此限制不是对全部通用 artifact 消费者的完整审计。尚无该早期图像候选部署到家庭设备的证据。

RGB 肤色与红笔或其他订正颜色可能相同，无法仅凭颜色证明某个像素被手遮挡；不可信遮挡区域必须保留原画面，不能以旧帧擦除当前订正。

## 日报读取候选的历史隔离修正（未补充部署与验收证据）

以下保留早期隔离候选的实现说明与未验边界；本轮文字草稿更新未完成这些历史报告路径的重新审计。

该历史隔离候选对当前会话及周目标、周期目标实际引用的历史任务检查来源；无来源的普通任务仍可保留，历史多帧候选、不匹配或缺失来源不作为报告事实。合法同孩子跨会话作业必须有对应的延续回执，来源指纹和冻结依赖绑定回执及来源状态。日报汇总使用数据库中的会话结束时间。家长本机预览遇到不可核对来源时显示中文说明并保留记录。已发送日报不会被静默修改。

新增隔离修订沿原作业、修订与承接回执验证多次承接、防止环路；日报读取和提交在各自数据库快照重核任务归属、来源及指纹，并对提交前及已生成 summary 的来源变化阻断或重新生成。已批准或发送的独立快照不被这些拒绝路径改写。旧日报如果缺少任务来源指纹，不把旧摘要和当前明细拼成可信报告：标记为历史内容无法核验，保留原日报及已批准/已发快照并停止自动发送。家长本机授权后可只读查看保留的摘要和沟通建议，明确标注未经核验；该入口不能创建更正版本或重发旧稿。承接链上原作业、最新修订、OCR 版本或范围授权变化时，不撤销已发生的承接事实，但停止将其作为当前报告依据；有效的范围确认需匹配原始授权回执，并重算正式来源版本。

这是局部代码候选，不代表全部 artifact 消费者、旧日报纠正或可撤销的人工作业/完成证据修订已完成。无可自助修订完成证据的家长流程时应人工核对；旧系统迁移、家机和两名孩子真实数据均未通过验收，产品状态保持 partial。

旧日报只读响应会等待底层发送协程结束后才释放删除/恢复保护：合成测试显示若发送协程忽略取消，保护会持续占用，直到该协程结束；五秒发送时限不能保证此类情况下五秒内解锁。Mac 本地 Uvicorn 0.35.0 的 h11 和 httptools 合成背压测试均能响应取消并在断连后返回，但尚不能证明 Windows 打包环境和所有网络状态都如此。已交给传输层的字节也无法撤回；真实目标运行时的断连、退出和恢复仍是待验收事项。

## 既有引用的回退边界

已有候选若曾关联作业或任务，不应自动删除作业、孩子确认、任务事件或已发送报告，也不应自动判断孩子未完成任务。应先只读定位引用和由作业派生的计划，保留原始记录及报告版本；再引入可撤销的审核事件，单独撤销候选的证据资格并标记需要复核。家长或孩子重新核对后，追加来源修订事件和必要的更正报告。已发送报告不能静默修改或假装撤回。

原报告记录，日报任务查询、`report_source_fingerprint.py` 和 `daily_report_frozen_dependencies.py` 尚未完整绑定并校验来源类型、归属、状态及审核事件。历史污染检测、报告更正、持久化恢复和目标 Windows 验收均未完成；本轮未补齐这些证据，不能以早期图像候选的写入拒绝测试证明历史日报已安全。

## 后续验收与剩余能力

后续重点是验证已接通的文字草稿能在真实书写、遮挡、订正、翻页、断流和恢复中保留正确来源与状态。可靠可见区域证据、同版式纸张切换隔离、候选纠错确认、目标设备上的隐私删除与恢复，以及真实高拍仪 OCR 质量仍需验收。早期 `DocumentPageCandidates` 原语的存在不能自行证明同页、手部掩码或擦改；当前文字配准也不能把遮挡期间的旧笔迹自动视为当前内容。
