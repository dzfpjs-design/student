# 高拍仪多帧候选：暂停与待完成事项

状态：`partial`，不可部署为完整多帧识别功能。本分支不启用跨帧图像拼接，持续观察仍使用单帧。RGB 肤色与红笔或其他订正颜色可能相同，无法仅凭颜色证明某个像素被手遮挡；对不可信遮挡区域必须回退原画面，不能以旧帧擦除当前订正。

多帧候选 API、OCR 工作流与底层 OCR 写入均拒绝新候选。历史上若已存在 `document_ocr_candidate`，新建及修改作业、任务完成和相关操作重放不能将它当成有效 OCR 证据；此限制不是对全部通用 artifact 消费者的完整审计。当前尚无该候选部署到家庭设备的证据。

## 日报读取候选的隔离修正（尚未部署）

本分支候选对当前会话及周目标、周期目标实际引用的历史任务检查来源；无来源的普通任务仍可保留，历史多帧候选、不匹配或缺失来源不作为报告事实。合法同孩子跨会话作业必须有对应的延续回执，来源指纹和冻结依赖绑定回执及来源状态。日报汇总使用数据库中的会话结束时间。家长本机预览遇到不可核对来源时显示中文说明并保留记录。已发送日报不会被静默修改。

新增隔离修订沿原作业、修订与承接回执验证多次承接、防止环路；日报读取和提交在各自数据库快照重核任务归属、来源及指纹，并对提交前及已生成 summary 的来源变化阻断或重新生成。已批准或发送的独立快照不被这些拒绝路径改写。旧日报如果缺少任务来源指纹，不把旧摘要和当前明细拼成可信报告：标记为历史内容无法核验，保留原日报及已批准/已发快照并停止自动发送。家长本机授权后可只读查看保留的摘要和沟通建议，明确标注未经核验；该入口不能创建更正版本或重发旧稿。承接链上原作业、最新修订、OCR 版本或范围授权变化时，不撤销已发生的承接事实，但停止将其作为当前报告依据；有效的范围确认需匹配原始授权回执，并重算正式来源版本。

这是局部代码候选，不代表全部 artifact 消费者、旧日报纠正或可撤销的人工作业/完成证据修订已完成。无可自助修订完成证据的家长流程时应人工核对；旧系统迁移、家机和两名孩子真实数据均未通过验收，产品状态保持 partial。

旧日报只读响应会等待底层发送协程结束后才释放删除/恢复保护：合成测试显示若发送协程忽略取消，保护会持续占用，直到该协程结束；五秒发送时限不能保证此类情况下五秒内解锁。Mac 本地 Uvicorn 0.35.0 的 h11 和 httptools 合成背压测试均能响应取消并在断连后返回，但尚不能证明 Windows 打包环境和所有网络状态都如此。已交给传输层的字节也无法撤回；真实目标运行时的断连、退出和恢复仍是待验收事项。

## 既有引用的回退边界

已有候选若曾关联作业或任务，不应自动删除作业、孩子确认、任务事件或已发送报告，也不应自动判断孩子未完成任务。应先只读定位引用和由作业派生的计划，保留原始记录及报告版本；再引入可撤销的审核事件，单独撤销候选的证据资格并标记需要复核。家长或孩子重新核对后，追加来源修订事件和必要的更正报告。已发送报告不能静默修改或假装撤回。

现有日报任务查询、`report_source_fingerprint.py` 和 `daily_report_frozen_dependencies.py` 尚未完整绑定并校验来源类型、归属、状态及审核事件。历史污染检测、报告更正、持久化恢复和目标 Windows 验收均未完成，不能以本分支的写入拒绝测试证明历史日报已安全。

## 后续真实功能

可在限定授权内探索按时间、页面及位置绑定每帧 OCR 文本与冲突候选，利用现有 OCR 文本几何和局部图像配准；必须先验证同页和可见区域，不能将遮挡期间的旧笔迹自动视为当前内容。现有 `DocumentPageCandidates` 是未接入的文本候选原语，不能自行证明同页、手部掩码或擦改。可靠手部区域、页识别与配准、红笔和新旧笔迹冲突、候选纠错确认、隐私生命周期及真实高拍仪和 OCR 效果均需验证。
