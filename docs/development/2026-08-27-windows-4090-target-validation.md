## 本次发现并修复

1. Windows安装冒烟仍断言旧的SQLite v57；已更新为v58，并让打包门禁对首次启动和覆盖升级两处断言做精确检查。
2. 原Windows PNP盘点扫描全部设备和全部驱动，导致测试超时；现只查询`Camera,Image`类和对应驱动属性。
3. 打包Electron把`resources/app.asar`文件当成Agent工作目录，导致窗口能打开但本地服务无法启动；现在打包环境使用`process.resourcesPath`，并有回归测试。
4. Windows PowerShell 5对无BOM UTF-8中文字面量、原生参数引号和多行`python -c`处理不一致；冒烟脚本已改为ASCII路径发现、参数化SQL和临时Python文件。
5. 普通Windows不一定存在CI专用`RUNNER_TEMP`；Agent和安装冒烟现可回退到系统临时目录。
