# 全语音控制与真实执行回执修复

状态：进行中。完整产品仍为20域partial、0域六层complete；本文件不替代完整交付范围。

## 实际失败与根因

Windows实际对话中，改唤醒词被回复为必须家长点设置，没有执行能力；摄像头打开被记录completed但随后又称未打开；高拍仪状态询问被误派拍题；停止遮挡提醒只有口头承诺；当前页面为空时陷入固定回复，并把本地播报再次当成孩子输入。

这些问题属于能力缺失、执行回执不实、状态查询缺失和语音来源不确定处理缺失，不是简单换提示词或ASR模型可以全部解决。

## 本轮验收门槛

1. 日常语音改名：云端提取候选，孩子语音确认后通过真实桌面存储保存，立即生效且跨重载保留；候选阶段不声称已保存；失败可重试。
2. 摄像头：打开等待真实首帧和租约，暂停停止track并释放相应租约；只停摄像头不能连带停止麦克风或高拍仪。
3. 状态查询：查询当前renderer设备事实，不触发拍摄或重新打开，不把历史租约当当前可见，也不把视频流存在等同看到了孩子。
4. 高拍仪：持续监控开关、当前页面查看、遮挡提醒偏好均有执行者和真实回执；偏好按孩子持久保存，重启后恢复。
5. 回声：只有实际播放重叠且同会话登记的长逐字片段标记来源不确定；原转录保留但不再播报，不入云端历史或学习证据。孩子播放后复述、改变数学符号、加入新内容正常处理。
6. 全能力审计：注册能力逐项核对执行所有者、前端接收、阶段限制、失败路径与结果凭据；禁止dispatch=false却回报completed。家长敏感操作可语音发起但仍需家长鉴权。
7. Windows：独立合成档案中使用真实摄像头/高拍仪及真实云端规划验证，清楚区分注入转录的控制器测试与真实儿童声学测试；部署前完整备份并校验家庭数据、声音和密钥配置不变。
