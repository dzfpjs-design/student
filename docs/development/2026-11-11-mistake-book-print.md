# 错题本筛选与打印

状态：`partial`。本地代码、相关自动化和构建通过；尚未部署 Windows，实际 Electron 打印、PDF 分页及纸张输出未验证。完整产品仍为 20 域 `partial`、0 域六层 `complete`。

## 用户流程

在当前孩子的「智能错题本」打开「打印错题本」，按学科、入册日期、题目/知识点/错因关键词、错因、掌握情况、复习作答次数筛选，勾选题目，生成 A4 预览，再选择系统打印或保存 PDF。

打印包括题干、已有原题裁图、错因与知识点、掌握情况及依据、复习次数明细、最近/下次复习日期。可显示当时作答、预留手写订正区、每题另起一页。长题可续页；实际分页需在系统打印预览或 PDF 中核对。

- 只打印当前筛选范围内勾选的题目。重新读取保留仍存在的勾选，不自动加入新题。
- 日期按入册时间计算；复习次数按当前题干已保存的作答记录统计，含原题复做、变式作答、既有强化/验证/复测。讲解、取消和未完成操作不计入。
- 「已掌握」必须来自有效独立验证与延迟复测证据；一次答对显示待复测。题干修改后，旧题的统计、诊断和掌握状态不能直接沿用。
- 无云端分析的旧错题仍可按已有诊断筛选；候选诊断标记待验证，不伪造分析。
- 读取失败、无结果、无选择、非法范围、图片失败、取消、保存失败均有反馈；修改条件使旧预览失效。图片缺失时阻止生成，用户可明确取消附图后再生成。
- 打印不改变学习记录、不发起模型分析。系统打印回调只显示「已提交系统打印队列」，不声称纸张已经输出。

## 实现边界

`GET /v1/children/{child_id}/mistake-learning/print` 是已有本地认证下的完整只读 SQLite 快照，包含正式错题和手动录入题，不分页截断，不刷新图谱，不修改掌握状态。题图读取增加可选 `source_revision` 校验，保持旧调用兼容，变化返回 409。

React 静态文档转义题目文字。`window.desktop.printMistakeBook` 通过当前主窗口 IPC，创建独立临时会话，禁止脚本、外网、导航与新窗口，只接收内联样式和已读取的图片。PDF 先写同目录临时文件再替换目标；取消或写失败不宣告成功。HTML 不落盘。

单次文档限制 32 MiB，原图提前限额并提示分批。没有静默截断或自动省略题图。预览与原生打印消费同一份冻结文档。

## 下一动作与发布界限
