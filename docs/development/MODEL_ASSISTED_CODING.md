# 模型辅助编码执行约定

2026-09-12用户授权：简单编码可使用千问Token Plan和DeepSeek，由Codex验收，以节省Codex额度。本约定不改变应用运行时的模型配置。

- 可委派：小型纯函数、重复性转换、边界测试草稿、限定范围的代码审阅。Token Plan仅在凭据及额度可用时优先；否则使用已授权DeepSeek端点的实际可用模型。
- Codex保留：需求拆解、架构、权限与隐私、持久化、并发恢复、整合、反例审查、实际运行与最终验收。外部模型声称通过不构成证据。
- 只发送人工审查过的最小脱敏任务。不得附带家庭数据库、影像、声音、教材、转录、知识库、环境变量、配置文件或密钥。凭据仅从本机安全存储读取到请求内存，不打印、不写入生成代码。
- 输出先保存隔离候选，审查导入及副作用，再在隔离环境运行。禁止直接执行未经审查的生成脚本，或让模型覆盖主工作树。
- 简单任务限制输出与重试，关闭不必要的推理消耗；记录真实模型、输入输出token、失败和本地验收。截断、空输出、弱断言或假实现均拒绝。
- 主测试和完整产品验收门槛不降低；使用模型辅助编码不授权重启已停止的原子提取或监控，不授权部署或扩大孩子数据上云范围。

首个受控任务是合成SQLite JSON边界测试，DeepSeek官方models接口实际返回可用轻量模型`deepseek-flash`。原候选保留在`/private/tmp/hsc-code-delegate-sql`，发现参数映射错误及弱断言后拒绝入主；修订候选在`/private/tmp/hsc-code-delegate-sql-v2`。这些是辅助编码质量记录，不是儿童语音或教学效果证据。
