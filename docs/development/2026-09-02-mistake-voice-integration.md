# 高拍仪错题、语音陪伴、记忆与长期回顾联调

日期：2026-09-02（本地）
产品状态：partial。本文记录实际执行过的链路，不缩小完整产品范围。

## 本次根因与实现

此前错题上下文依赖 React 组件临时状态，服务端将“对”“我选 B”“明白了”当作独立命令；组件侧流程与 Agent Runtime、讲题、复测互相脱节。本次增加本地 `MistakeDialogueService`，将焦点及每次操作写入数据库，而不是增加泛化的“我听到了”回复。

数据库版本 69 新增 `mistake_dialogue` 和 `mistake_dialogue_event`，保存会话/孩子/题目绑定、阶段、原答案、题干确认、错因线索、提示依赖、复测状态、幂等键与请求摘要。导出和按孩子删除包含两表。既有记录不重建。

- `POST /v1/sessions/{id}/mistake-dialogue`：从本地 OCR 候选开始或恢复同一题。
- `GET /v1/sessions/{id}/mistake-dialogue`：恢复服务端权威状态。
- `/agent-turn` → `mistake.dialogue` → `/agent-turns/{id}/execute`：连续语音操作的统一执行路径。
- `mistake.open` 从当天任务/到期队列恢复错题，随后短回答属于这道题，不重新猜学科或调用无关讲解。

## 完整链路

1. 高拍仪明确绑定 Fic760；不使用 L523 或任意摄像头作为替代。单次采集请求原生高分辨率，连续监控保持低帧率；页面图片仅在本机 OCR。
2. OCR v3 自动处理倒置；先区分双页再形成题干/选项。残缺页、低置信度和跨页布局不确定的块不进入可确认候选。对勾不是做错证据；红色痕迹只能提出候选。
3. 保留全部边界合格的题，批改痕迹只排序，不能隐藏其他题。孩子可说“第四题”选择；同页重号不擅自挑选。
4. 孩子只核对系统是否读错题干、实际原答案或题目归属，不判断正误和“是否确实需要订正”。老师已批改题由严格绑定的批改标记判定；自主拓展习题由版本化标准答案判定；智能体提供的题由呈现时冻结的答案与评分规则判定。权威证据充分时系统自动创建错题或正确题独立复测；证据不全时持久待评分，不编造、不重复新增。跳过已保存错题只暂停，不排除薄弱点。
5. 孩子解释为什么这样作答，记录为置信度 0.6 的错因假设，不凭自述或一次讲解宣告已诊断/已掌握。
6. 仅将单题已确认文字、原答案和这次追问交给受限讲题 API。整页、照片、家庭画面和只读原子知识上下文不进云端请求。
7. 同一讲题结果产生自然女声和结构化板书；第一段可听音频触发板书时序，插话停止后续板书。讲解失败保留错题/回答，支持语音重试。
8. “明白了”只推进到独立检查。提示后回答不计独立；不得抢跑阶段、用同一变式重复凑证据、跨孩子取题或提前完成延迟复测。
9. 通过当前检查后保留 48 小时/7 天门槛，到期进入当日计划；新会话恢复原错题。长期模型投影使用证据值与时间窗口指纹，修订不是靠行数变化才能更新。
10. 排除错误识别的错题后，从有效薄弱点及长期记忆投影中撤回，原事件保留用于审计。取消拍题不会启动采集；换页使用独立幂等键；重试后读取当前进度，不重放最初提示，也不覆盖已经到达的新回答。

## 六层验收

|---|---|
| code | 连续语音状态、原答案/错因、教学、复测及恢复实现存在；仍需代表性多题/多学科持续验证 |
| integration | 本地真实页回放 → OCR → 语音识别 → Agent → 错题数据库 → 实际讲题模型 → 女声/黑板 → 复测排程通过 |
| durability | HTTP 跨应用重建、Electron 重载、候选/错题去重、跨天计划和导出通过；完整后端分段回归覆盖现有备份恢复套件；未验证 Windows 跨机 |
| target_runtime | 本机 macOS Electron 验证；最新高拍仪实时采集被设备缺失阻塞；最终 Windows 未验证 |
| real_user | 尚未验证两个孩子真实发音、免点击持续学习、实际错误反馈和室内回声 |
| outcome | 尚无真实 48 小时/7 天独立复测及成绩改善数据，不得宣称成绩提高或已经掌握 |

## 后续门槛

- 设备：Fic760 重新出现后，从新帧重跑整链，包括遮挡语音提醒和重新对焦，不以旧帧冒充实时。
- 模型/数据：低可信知识点不能强行归类；代表性手写、数学公式和重号/共享选项版面继续评测。
- 体验：确保新拍错题、主动提醒、暂停/继续、语音重试都由 Agent 驱动，不要求孩子操作功能键。
- 教学：真实孩子提供原作答并通过独立复测后才更新对应能力，不把听讲次数、使用时长或自述直接当作掌握。
- 原子知识提取和监控保持停止；已有未审核内容只作线索，不作为知识掌握证据。
