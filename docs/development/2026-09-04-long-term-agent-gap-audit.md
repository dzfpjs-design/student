# 长期陪伴智能体复盘与交付门槛

日期：2026-09-04，最终升级验证延续至2026-09-05。状态：partial，本轮修复已部署，真实儿童与效果层未验收。

## 最终目标

两个孩子每天仅通过语音，从回家报到、课堂与作业整理、时间安排、拍题、讲解与独立检查，到错题复习、休息陪伴、结束学习与家长反馈，形成跨天可恢复的教育过程。对话流畅、调用工具和保存聊天记录不是目标本身；需要有独立作答、迁移复测、任务恢复和家长行动证据。

本轮未改用另一个后台教学模型冒充质量提升；采用独立代码复审、反例重放与持久化测试重新检查最终目标。完整范围仍为交付总账的20个功能域，无功能删减。

## 长期记忆协议

- 写入：已完成的真实孩子回合，或孩子明确的记住指令。排除控制、测试、转述、模型原话、重复确认和失败回合。事件必须为已发生自述，不能把请求记为事实。
- 归属：child_id + session_id 校验；动作ID全局去重，跨孩子复用报冲突。
- 置信度：表示来源与提取可信度，不表示孩子叙述客观真实；不诊断人格或直接写掌握度。
- 检索：本地按内容相关性、重要性、时间排序，返回来源与local-only声明。通过语音查询，无需孩子点击。
- 教学适应：只允许明确教学语境的stepwise/visual/example、gentle、slow枚举。兴趣不能自动等价为学习风格，否定不能被忽略。
- 遗忘：清除记忆内容和证据，保留不含原文的语义墓碑防旧回合迟到复活；旧缓存不能重新读出删除内容。
- 留存：偏好180天、自述90天、经历与学习困难30天；访问及维护执行过期；活跃记忆128条、内容行256条上限。原始会话记录与备份遵循独立删除范围，不虚称一次遗忘已删除所有历史介质。
- 云边界：回忆正文不进入聊天模型、规划器或云TTS；历史中的记忆来源回合亦被排除。回忆用设备本地声音，若没有可用离线声音则明确失败，不偷偷换云声。
- 家长：鉴权后搜索、查看来源、删除；状态持久，刷新与重启一致。全部历史删除覆盖记忆、执行收据及相关审计。

## 不得隐藏的剩余门槛

1. 声学质量：文本无法证明真实声源。Windows真实远场麦克风、扬声器、键盘和儿童连续发声仍需测漏听率、误触发率、打断延迟；不能用模拟音轨通过冒充。
2. 教学质量：理解/独立/迁移/保持四维目前保留证据与复测流程，不是已校准教育测量。真实题目来源、映射覆盖、评价一致性与错误提示率必须持续测量。
3. 数据质量：原子图谱和教材审核未完成；全量提取与监控按用户要求保持停止。未审核来源不能用于批准掌握状态，缺少题库的专项不能假装已覆盖。
4. 运行质量：新代码必须通过稳定回归、Windows构建和安装后记忆/语音/设备验证，不能引用旧包成绩替代。
5. 长期效果：两名孩子的独立复测、提示依赖变化、校内错误和家长执行反馈尚不是已证实收益；需要观察数据，不承诺成绩因果提升。
