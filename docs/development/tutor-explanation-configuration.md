# 讲题服务的本机配置

讲题、错因分析及相关引导使用家长确认的专用 DeepSeek 服务。服务地址和密钥属于本机配置，不应提交到 Git 或公开的安装包。首次使用时，在桌面客户端的家长中心解锁，打开「讲题与错题分析模型」，填写服务的 HTTPS `/v1` 地址和模型名称，输入密钥并确认题目及必要学习上下文会发送给该服务，然后保存。密钥输入框不会回显已保存的值。

已有版本若保存过讲题密钥，新版会保留该密钥；家长只需填写并确认服务地址和模型。升级不会自动猜测或更换服务地址。配置不完整时，专用讲题和错因分析会提示家长完成配置，不会偷偷切换到其他模型；其他模型能力和原判题路由仍使用其各自配置。

配置由桌面客户端通过系统安全存储加密保存在当前 Windows 用户资料中。保存完成后本地服务会重新加载；如果结果显示服务尚未确认更新，请重新解锁家长中心读取配置，勿反复提交。系统安全存储不可用或家长身份失效时，修改会被拒绝。

验证时需先取得服务所有者提供的地址、密钥和模型许可，使用不含真实学生数据的题目检查连接，然后在目标 Windows 上检查解锁、保存、应用重启、服务重启和错误恢复。本说明不代表任何真实服务或现有安装已通过验证。

如果客户端提示讲题配置恢复占用或上次恢复未完成，先退出所有学习伙伴窗口和相关后台进程。确认无人再使用该数据目录后，在客户端提示的本机数据目录内，只删除名为 `tutor-explanation-settings.lock.recovery` 的空目录，然后重启客户端；不要删除任何其他文件，尤其保留 `tutor-explanation-settings.pending` 和已加密的设置。若该目录不是空的或无法确认所有进程已退出，保留现场并寻求维护协助。
