# 真实学习材料驱动的部署候选版本

目标：高拍仪实际教材/作业经核对后，进入云端理解、错题补救、可核验复测、长期反馈与计划，不要求原题预先存在内置题库。

发布边界：构建部署候选及隔离验收，不覆盖现有 Windows 安装或家庭数据库。原子批量提取与监控保持停止。完整 PRD 范围不缩减，模型教学质量和真实学习效果不得以替身测试代替。

## 必须闭合的路径

1. 学习期持续取帧，安全书页文字/裁切交给合适模型；暂停后迟到结果不得写回。
2. 孩子语音确认实际题面与原答案，保存来源和错因假设；照片不是作答正确性证据。
3. 非内置原题也能准备变式；仅上传安全教学文字，不发送原页、个人信息、孩子答案或行为画像。
4. 生成题先入候选审核。封闭答案与开放题参考评价分开；未批准或仅关键词评分不得累计可靠掌握。
5. 批准题进入原错题的复测/计划；源材料删除、修订、排除会使派生题失效。重启、重复动作、模型失败与取消可诊断和恢复。
6. 构建产物不得包含家庭数据、密钥、原始教材或视频；必须核对源码与打包服务一致，记录目标运行时门槛。

## 本轮关闭的代码缺口

- 高拍仪新错题没有 diagnostic_item_id 时，现已支持从本机已确认且归属正确的真实采集候选生成变式。来源文本、版本、会话和归属固定；修改、删除、排除原题会撤销派生题的有效性，模型迟到结果不越过来源检查。
- 新封闭题接受完整精确答案及有理数评分；开放题仅保留参考评价。结构校验不等于答案正确，生成结果必须经家长审题批准才可进入可靠复测。
- 家长可同时查看原题和变式。生成任务有状态、失败原因与明确重试；重试动作跨重启保存，同一动作不会重复提交付费请求。缺图说明、敏感文本、来源失效不能通过重试绕过。
- 普通长书页先检查整页风险再选取有边界的文字片段，保留截断标志。后台模型超时与实际配置匹配；暂停/恢复代次使迟到结果失效。可确定未发出的请求允许恢复，付费状态未知的请求不自动重复发送。
- 材料理解的请求级模型适配器限制单次网络发送，不改变共享语音模型；返回结果被撤销时仍记录已发生的调用成本。页内长文本块不再因单块超过 600 字直接丢失。
- Windows 构建门禁检查白名单资源、模型文件哈希、符号链接/家庭数据/密钥文件、真实 x64 PE 服务和源码/输出新鲜度。时间戳仅是新鲜度检查，不冒充可重现构建证明。

## 大库启动阻断与修复

- 两次旧候选均在导入 49,619 段文本后卡在第二次 `Waiting for application startup` 超过 90 秒；首次空库启动与导入成功。旧失败 JSON 保留在 `docs/evidence/material-20260906/curriculum*.json`，不以增加超时掩盖。
- 根因是 schema.ensure_schema 无条件遍历全部 segment 回填 occurrence；目录 bootstrap 中每个节点/关系再次调用 schema，造成规模放大。
- 图谱 schema v31 通过持久增量队列记录新增/修改 segment，旧数据只回填一次，标记/回填/队列清空在 savepoint 中一起成功或回滚；普通 writer 的显式 occurrence INSERT 不冲突，不覆盖人工/去重偏移。
- 内容包导入在同一内容事务内补 canonical occurrence 并清空增量队列，最后才写交付回执；失败可重新导入，不依赖下次应用启动补漏。模型与图谱原子任务都没有启动。
