# 持续书桌学习理解与过程记忆

状态：代码、集成、持久化与 Windows 覆盖安装已验证；真实课本/手写长会话与孩子学习效果仍待验收，完整功能为 partial。

## 用户旅程

孩子用语音开始学习后，高拍仪持续取帧；无需按拍照或识别按钮。稳定页建立基线，书写和翻页形成新版本。页面遮挡、设备断开、任务暂停与结束必须有对应处理。连续观察不等于连续上传或全程录像。

前台语音不等待页面分析。孩子询问当前页面时，智能体读取本会话最新的观察证据；没有新鲜可靠内容时明确说明，不自行开始无关讲题。具体题目仍需确认题干、孩子原答案与推理步骤，再进入既有错题、讲解、独立检查与延迟复习闭环。

## 处理与证据边界

1. 本地帧分析：稳定性、翻页、遮挡、可观察书写变化。不能将没有变化解释为分心或不会。
2. 本地 OCR：转正、版面与题块、文字变化、置信度。低置信度保留复核标记，不覆盖为正确题干。
3. 云端文本分析：仅发送脱敏后的当前学习文字及必要变化，不携带家庭画面、原始长期记忆或未批准原子图谱证据。输出必须能回指原文；错因是待验证假设。
4. 云端视觉补充：必须独立配置真正支持图片的模型，不能将文本模型冒充视觉模型。只允许通过本地安全检查的页内内容，不能证明页面隔离时拒绝传输。房间、孩子、持续视频与教材 PDF 不上传。
5. 长期记忆：去重保存学习材料、关键步骤变化、待核对困难及后续验证的来源。自述、OCR 观察、模型推测与独立检查不得混为事实；支持检索、修订、遗忘、导出与删除。

## 运行约束

- 单高拍仪持有者；明确拍题时连续监控让出设备，结束后恢复。
- 有界队列、幂等页面版本、模型预算与超时；旧页不得覆盖新页焦点。
- 暂停、结束、换孩子立即释放设备；迟到结果不得发声或误写到其他会话。
- 已持久化结果跨重启恢复。未知模型执行不盲目重发；错误有结构化状态但不泄漏正文与密钥到日志。
- 不重新启动已经停止的原子知识点提取与监控。

默认调度：本地每 500ms 检查低分辨率帧，稳定变化后的 OCR 最短间隔 15 秒且仅一个请求在途。后台分析循环每 2 秒取一个持久任务；云端文本每会话最多 60 次、最短间隔 30 秒，页内视觉每孩子每天最多 60 次、最短间隔 60 秒并预留 token 预算。达到限制保留明确状态和本地记录，不表示学习已完成或页面没有问题。

## 剩余门槛

1. 云端视觉当前是有安全门的页内文字/公式补充，并非任意教材整页图片理解。彩色教材、复杂图形、照片及本地无法隔离的手写块可能被拒绝；应保持结构化阻塞与语音说明，不能宣称已经理解。
2. 模型观察、错因假设和孩子口述需要与确认题干、原答案、推理步骤及独立复测合并验证。记录了说明不等于已完成错因诊断，也不等于成绩提升。
3. 合成页面、真实模型 HTTP 和自动回归不能替代 Windows 高拍仪前真实课本、手写、遮挡、长时间连续学习的整体验收。
4. 两名孩子真实无点击使用、误介入率、漏看率、学习收益和长期策略有效性仍未通过验证。

代码、集成、持久化、Windows 设备、两名孩子使用、学习效果分别验收；任何单层通过都不等于完整功能交付。
