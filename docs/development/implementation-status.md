## 4. 到货后验收顺序

1. 登记设备铭牌、系统枚举名、驱动、VID/PID或网络协议，不根据商品宣传推定能力。
2. 在家长中心扫描两台视频设备，分别选择观察摄像头和高拍仪，执行“验证并保存绑定”，重启后核对角色保持不变。
3. 分别验证观察摄像头和高拍仪的打开、预览、拍摄、释放、权限拒绝和其他应用占用；运行中拔出一台时不得切换到另一台。
4. 在家长中心依次运行双路快速检查、双设备并发30分钟、观察摄像头60分钟和高拍仪60分钟；观察摄像头还必须在实际座位布置下通过场景有效性检查，最近状态样本不能持续为`unknown`。只有稳定性和有效性同时满足，才可声明观察角色通过。一次打开验证和60秒快速检查都不替代这些门禁。
5. 验证运行中拔出、重新插入、应用崩溃、隐私暂停和会话结束后的操作系统占用状态。
6. 用非敏感样本跑三次完整每日闭环，再允许录入真实孩子数据。
