## 1. 构建输入

- Windows x64，Node.js 24，Python 3.11。
- `npm ci`安装固定前端与Electron依赖。
- 使用`py -3.11 -m venv .venv`后运行`.venv\Scripts\python.exe -m pip install -e "services/local_agent[dev]"`。如用`uv venv --python 3.11`创建无pip环境，改用`uv pip install --python .venv\Scripts\python.exe -e "services/local_agent[dev]"`。
- `npm run models:download`下载本地中英ASR模型；模型不进入Git。
- `build/installer.nsh`必须存在且未被Git忽略，用于卸载时清理登录自启。

## 2. 自动发布门禁

Windows流水线按以下顺序执行，任一步失败都不得上传为可试用安装包：

1. TypeScript类型检查、Vitest和Pytest；Vitest在Windows runner上实际执行固定无参数PNP盘点，非Windows只显式跳过该一项。
2. 下载四个ASR运行文件，并按仓库固定清单校验最小体积和SHA-256。
3. PyInstaller生成`dist/home-study-local-agent.exe`。
4. 独立启动该exe，验证健康、SQLite v99、启动恢复点和Windows传感器释放平台门禁；对已配置家长PIN连续提交5次错误值形成锁定，确认正确PIN也不能绕过，然后优雅关机。使用同一数据目录再次启动exe，运行黑盒`assert-locked`阶段确认锁定跨进程保持，再次优雅关机。
5. Electron生产构建和`npm run verify:package:win`打包输入门禁。
6. NSIS生成安装包。
7. 静默安装后按同一清单重新校验模型SHA-256；用安装后Electron主进程执行`--hardware-inventory-smoke`，确认走`windows_pnp_cim_v1`且报告只含允许字段和实例哈希；执行`--model-settings-smoke`，用随机合成值验证Windows系统安全存储的加密往返、磁盘无明文和幂等清除，报告不得包含密钥材料且结束后不得残留模型配置；再验证桌面窗口、本地服务、SQLite v99、学习/语音/Agent/观察/错题/模型审计表、本地滚动运行日志、崩溃转储目录、每日自动备份和登录自启。
8. 写入非敏感家庭数据哨兵和一条“全部计划片段已完成、作业仍待完成”的旧错账，把测试库标记为v47并移除后续安全事件表后，在同一路径执行覆盖安装；确认应用建立带SHA-256的升级前恢复点、迁移到v92、创建安全事件表、周期报告刷新状态表、座位取景校准表、课程语料索引、官方课标来源、课程候选对齐审计、内化任务、课标对齐表、错题闭环表、多题采集候选事件表、连续错题对话及事件表、不可变决策记录与结果归因表，修复作业状态、保留哨兵、可再次启动并干净退出。自动化同时验证迁移已提交后失败会还原旧库，未来版本数据库会拒绝被旧应用降级打开。
9. 静默卸载，确认自启被清理而家庭数据、升级前恢复点仍保留。
10. 生成`release/SHA256SUMS.txt`并连同安装包上传。

开发机可运行`npm run build && npm run verify:package:win:static`，它不会冒充Windows exe验证。

普通Windows PowerShell 5人工验收时，使用`scripts/run-windows-installer-smoke-interactive.ps1`在已登录桌面会话执行；SSH非交互会话不能提供可见窗口证据。脚本在`RUNNER_TEMP`缺失时自动使用系统临时目录。

## 3. 数据位置

正式安装默认将SQLite、备份和授权保留的加密媒体写入Electron `userData`下的`family-data`目录。模型密钥、媒体主密钥和首次自启标记由Electron用户目录管理。测试或迁移时可以用`HSC_DATA_DIR`整体改写，`HSC_DATABASE_PATH`只用于明确的数据库路径覆盖。

卸载应用不得删除`family-data`。重新安装后应继续读取原数据库；跨电脑迁移加密媒体尚未交付，不得用普通数据库备份代替密钥迁移。

## 4. 目标电脑验收

1. 记录Windows版本、CPU、内存、可用磁盘、系统麦克风和BitLocker状态。
2. 用SHA-256清单校验安装包，在非管理员家庭账户完成安装和首次启动。
3. 重启Windows，确认应用自动进入等待页；关闭自启后再重启，确认不会启动；重新开启。
4. 建立两个非敏感测试档案，各跑一轮报到、计划、任务、复盘和日报，重启后检查隔离与恢复。
5. 强制结束应用一次，重新启动后确认活动任务暂停、传感器租约释放且异常恢复可见。
6. 执行手动备份与恢复；再用新安装包覆盖安装，确认家长运行状态显示升级前恢复点且家庭数据不变；最后卸载和重装，确认家庭数据保留。
7. 接入真实摄像头和高拍仪，先对照Windows设备管理器、驱动属性与铭牌核对自动盘点的厂商/型号、VID/PID和驱动，人工确认协议、PTZ和音频结论；再按测试计划完成双路30分钟、单路各60分钟、拔插和占用。
8. 跑一次实际会话后进入家长中心“Windows隐私释放”，核对设备管理器、Windows隐私指示和物理指示灯，再用相机/录音机重开当次每种设备。只有全部通过才登记系统级释放；刷新和重启后确认证据仍在。
9. 设置测试家长PIN并连续输错5次，记录锁定倒计时；关窗重开、Windows睡眠后唤醒及系统时钟同步后分别确认不能提前解锁，等待到期后确认首次错误只消耗新一轮第1次机会。
10. 在家长中心打开“本地问题记录”，确认`family-data/diagnostics/logs/runtime.jsonl`存在，能串起应用启动、本地服务启停、渲染进程异常和本地API调用的路径/状态/耗时/追踪号。日志单文件上限10MB、最多5份轮转；不得出现API密钥、会话令牌、请求体、原始声音、原始图片或原始视频，`crashes`不得配置上传。

### 4.1 语音与拍题人工测试会话

覆盖安装和启动检查通过后，先在候选源码目录执行：

```powershell
& .\scripts\collect-windows-test-session.ps1 -Action Start
```

然后完成全语音唤醒、连续对话、语音控制摄像头/高拍仪、倒置题面校正、遮挡提醒、错题识别、错因追问和进入错题库。不要在测试期间更换候选源码目录。测试完成后执行：

```powershell
& .\scripts\collect-windows-test-session.ps1 -Action Stop
```

工具会在`C:\HSC\test-sessions`生成本机私密会话目录和`*-PRIVATE.zip`。其中包含SQLite在线一致性快照、脱敏滚动日志、设备清单、安装文件哈希和关键行为表增量；不会复制原始音频、图片或视频，也不会自动上传。压缩包含家庭数据库，只能在家长确认后通过受控局域网取回，不得进入源码仓库、云盘或外部模型请求。若`PRAGMA quick_check`不是`ok`、会话号不一致、数据库快照失败或存在未结束的旧测试会话，停止验收并先修复记录链路。

## 5. 失败处理

- 安装包缺资源：阻断发布，先检查`verify:package:win`结果，不允许从开发目录手工补文件。
- 本地服务未启动：保留CI失败日志中的首个异常和应用版本，检查agent exe、模型路径、数据目录写权限。
- 数据库版本不是99、升级前恢复点缺失/哈希错误、覆盖升级丢失数据或无启动恢复点：按数据/迁移P0处理，不得继续设备验收。
- 家长运行状态显示“升级失败后已自动还原”时：旧数据仍可用，但当前安装包不得发布；保留恢复点和首个迁移异常，修复后重新覆盖安装。
- 卸载后自启残留或数据被删：按安装器P0处理。
- 家长PIN锁定可被应用重启绕过、到期后立即再次锁定或倒计时明显偏离后端状态：按本地访问控制P0处理；保留脱敏HTTP状态码与剩余秒数，不记录实际PIN。
- Windows CI通过但目标机失败：以目标机为准，记录系统与驱动差异，不将CI结果写成实机通过。
