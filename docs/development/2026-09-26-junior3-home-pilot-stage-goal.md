# 初三家庭试用候选版阶段目标

## 1. 阶段结果

在孩子进入真实测试前，交付一个 Windows 单安装文件。目标电脑安装后不再要求填写模型参数；DeepSeek 与阿里云 Qwen 配置从该电脑的系统加密存储恢复。孩子只通过语音完成日常学习，摄像头和高拍仪在学习期间持续工作，题目、错题、讲解、复测、记忆和计划形成可恢复闭环。每天形成一份测试诊断日报并自动发到 `parent@example.test`，用于第二天定位和修复真实问题。

本阶段不把几天试用冒充成绩提升。成绩、独立性和习惯结果必须由真实孩子的跨日证据验证。

## 2. 交付门槛

### 安装与配置

- 生成单一签名状态明确的 NSIS 安装文件，包含 Electron 前端、本地 Agent、OCR 和所需运行时。
- 覆盖安装保留两个孩子的档案、模型加密配置、设备绑定、错题、长期记忆和发送状态。
- DeepSeek 为文本主路由；阿里云 Qwen 为文本备用，并承担实时语音、ASR、陪伴音色和文档视觉。
- 不设置会让按量通道在当天人为停机的本地日额度；只保留稳定页门禁、内容去重、单请求互斥、服务商限流退避和失败恢复。

### 初三孩子闭环

1. 开机自动启动，默认麦克风可唤醒；进入连续对话后无需重复唤醒。
2. 孩子口述课堂与作业，智能体结合长期目标生成当天计划并取得语音确认。
3. 外接观察摄像头和高拍仪自动恢复绑定；未连接时能够理解语音重连请求并给出准确恢复提示。
4. 高拍仪持续采样；手、笔或书页遮挡不报错、不打断，恢复清晰后自动 OCR。
5. 页面按方向校正、稳定页去重，题目和实际作答进入统一作答账本；正误只由与题块绑定的老师批改、版本化标准答案或智能体出题时冻结的答案/量表判定。孩子只纠正题干、本人实际作答和题目归属，不确认正误。
6. 合格评分权威判错后自动建立错题，并形成错因假设、讲解、黑板同步、独立变式和到期复测；无权威作答保持待评分，未经核验的视觉推断不能更新掌握度。
7. 会话结束后把课堂、任务、题目、错误、提示依赖、情绪/习惯证据和下一步写入长期模型，第二天可以继续。
8. 生成孩子日报、薄弱点清单、次日计划和家长可执行建议。

### 测试证据与日报

- 本机持续保存会话、语音阶段、模型路由、工具调度、设备状态、OCR/视觉、题目去重、错题状态、记忆和发送回执；不保存原始连续音视频。
- 每日诊断日报至少包含版本、运行时长、学习会话、语音成功率和延迟、设备断连/恢复、OCR 页面与题目数、错题状态、模型失败/回退、未完成动作和需人工复核项。
- 应用自身作为 SMTP 客户端，不依赖 Foxmail、Outlook、Python、Node 或系统默认邮件程序。家长在家长中心一次性填写 SMTP 主机、端口、账号、应用专用密码和发件地址；密码由桌面系统安全存储保护，安装包内的本地 Agent 负责 TLS 投递。
- 发件采用持久 outbox 和日期幂等键；应用关闭或网络中断后，下次启动补发；提交结果未知时不自动重复发送。
- 固定收件人为 `parent@example.test`。邮件不附原始音频、视频、摄像头帧或模型密钥。

## 3. 验收矩阵

| 层级 | 本阶段通过条件 |
|---|---|
| code | 不存在演示回退；全部主链和恢复分支有实现与针对性测试 |
| integration | 前端、Agent Runtime、模型、设备、数据库、长期记忆、日报和邮件真实接线 |
| durability | 应用/后端/整机重启后配置、会话、题库、错题、outbox 和设备绑定可恢复 |
| target_runtime | 最终 Windows 电脑完成安装、语音、双摄像头、拍题、重启和真实邮件送达 |
| real_user | 初三孩子无需点击完成至少三天真实学习；问题均可由日志复现 |
| outcome | 至少一个薄弱点经过发现、教学、独立作答和延迟复测形成可靠改善证据 |

在 `real_user` 和 `outcome` 通过前，阶段状态只能是 `pilot-ready` 或 `pilot-in-progress`，不能称完整产品完成。
