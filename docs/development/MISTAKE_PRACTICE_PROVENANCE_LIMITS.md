状态：`partial`；本地测试不代表 Windows 实机、真实模型或孩子使用验收。

无图谱来源练习的新记录绑定孩子、错题、原题修订、变式题面、答案要点与解析；该指纹未绑定模型路由，也不是签名，不能证明旧版未记录的来源或抵御有写权限者篡改数据库。切换模型不会自动使已经生成的变式失效。无来源凭据的旧变式保留，但当前学习入口标记待重新生成。

新讲解续轮只使用最近最多八条中可核对的连续后缀：每轮核对所属动作、孩子、错题、原题版本、会话、图谱版本和该轮保存的文本；无法核对的较早历史仍保留，但不进入后续模型请求。该机制不证明完整历史链、模型真实性或最终学习效果。带已审核图谱的变式还需当前图谱版本一致；它的来源凭据不能证明模型生成结果完全符合图谱。

图谱相关旧练习在送云前检查当前相关标签授权；查询错误、撤销和已记录的失效日期均拒绝发送，题目与历史作答保留在本机。标签权表没有 `expires_at` 列时，现有数据不能表达具体失效时间，不能假定系统已知外部合同到期情况。每次模型请求前重验不是对外部授权库与网络提交之间的原子锁；已经交给网络或模型服务的内容无法撤回。
