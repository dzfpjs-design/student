# 云端优先语音智能体修复

状态：本轮云端优先语音修复已覆盖安装到目标 Windows，安装程序与隔离数据的真实云端验收通过。完整产品仍为 20 个功能域 partial，0 个六层 complete；本文件不代表孩子能力提升已经验证。

## 用户旅程与验收

孩子自然说话，经云端 ASR 转写，普通对话由云端模型结合近期对话和当前任务理解，选择已注册能力；本机执行能力、保存真实结果后回复。初始化起名、确认、跳过、重讲以及恢复教程也应接受自然表达。云端不可用不得将本地猜测或固定口令路径伪装为成功。

验收包括：同一含义不同说法均可拍题；否定关麦和询问摄像头不会执行关闭；没有请求不能自讲一元二次方程；含糊回应不能伪造作业检查证据；复合口述的两项作业分别保存，重复执行与后端重启不重复记账；教程退出不丢正在排队的录音；所有动作有结果回执。

## 根因与实现

- 旧编排器先匹配本地关键词，模型主要处理未命中内容，导致命中旧规则反而绕过自然语言理解。现将普通会话统一交给云端规划，模型输出接受注册能力、参数、当前话语引用与上下文门槛校验。
- 初始化曾把普通学习请求当作名字或教程答案，现使用持久化的云端语义路由。真正学习请求先保存教程暂缓状态，再将原话交给 Agent；命名和教程结果支持重放与删除，不跨孩子共享。
- 云端 ASR 失败曾静默采用本地猜测执行。现仅唤醒词可以保留本地降级，普通会话识别失败明确提示且不提交猜测。
- 连续对话保留近期完整完成回合，云端可获得当前任务、等待回答状态与允许传输的教学偏好。原始家庭影像、标记本地专用的图谱/记忆/掌握度证据仍不进入云端规划请求。
- 立即停止功能只识别明确独立的指令分句，不再把否定或询问中的子串当成操作。其他表达交给云端理解。
- 故事开场由云端生成并通过陪伴安全检查，执行器使用该开场而不是固定故事模板。
- 模型规划必须调用工具改变设备或任务状态，不能仅口头声称执行；模型不能覆盖动作类型、执行位置、孩子标识或本地隐私标记。
- 签到、课堂回顾和作业录入期间允许孩子先说作业、再补课堂内容，不再要求按页面阶段说话；记录不擅自跳转阶段，已经确认的计划也不被静默改写。
- 教程暂缓和唤醒词策略变化不再清理正在录制或排队的对话音频；只有孩子、设备、会话切换才重建对应录音资源。
