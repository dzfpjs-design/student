# 拟人学习伙伴：语音、形象与 Agentic 编排实施说明

更新时间：2026-08-27。这个模块服务于小学四年级与初三学生的同一个目标：孩子能把“说出今天的课和作业—确认—获得计划—随时打断—回来继续”当作一件自然、可控的事，而不是把系统当成家长或朋友的替代品。

## 已接入的纵向切片

现有本地 API 已经是系统记录的唯一来源：`/asr` 将本地 ASR 结果写入 `voice_input`，`/agent-turn` 把意图、行动、模型审计写入 `agent_turn`，客户端执行已允许的计划/课堂/作业工具，再以 `/agent-turns/{id}/outcome` 写回完成或失败结果。恢复时从 `daily_session`、草稿和 `agent_turn` 读取，而不是重放一个演示脚本。

| 阶段 | 实现与约束 |
| --- | --- |
| 听 | 浏览器录音约束启用单声道、回声消除、降噪；本地 VAD 在 1.2 秒静音后截句；同一时刻只允许一个录音所有者。|
| 听懂 | Sherpa-ONNX 本地 ASR；缺模型时 API 返回 `ASR_MODEL_NOT_READY`，不上传音频或假装识别成功。|
| 澄清/行动 | 既有状态机按 `check_in → classroom_recall → homework_capture → plan_review → study` 限制意图；低置信最多澄清四轮，关键隐私/安全命令先本地处理。|
| 工具 | 仅允许计划、课堂回忆、作业、错题/题目捕获、知识诊断提问、观察更正等明确定义动作；每项都有 client action id、结果和失败码。|
| 说/打断 | `companionVoice.ts` 定义可取消的 PCM 流提供方；录音检测到说话会停止播报。管理型自然语音不可用时，界面明确标为“系统临时播报”，不能视为自然女声交付。|
| 恢复 | 已完成的行动和草稿持久化在本地数据库；前端的待处理口述只在当前界面排队，不会在崩溃后伪造执行。|

## 唤醒词与连续对话状态机

每个孩子首次进入学习伙伴区域时，在已绑定麦克风就绪后直接说出一个 2 至 12 字的本地唤醒词；本地识别成功后自动核对、保存并进入唤醒监听，不要求孩子点击功能键。配置经 Electron IPC 原子写入本机 `companion-wake-words.json`，按 child ID 隔离；应用或本地服务重启后会恢复，不保存设置录音。纯数字、空格、过短、过长及非法字符会被拒绝；可见输入和按键只作为家长维护或故障恢复入口，不是孩子日常流程的前提。

运行时只有四个对孩子可解释的状态：未初始化、唤醒待机、连续对话、暂停。唤醒待机持续使用本地 VAD 和 Sherpa-ONNX ASR，未命中唤醒词的转写不会进入 Agent、工具或云端；命中后可在同一句继续说命令，也可只说唤醒词并等待“我在，你接着说”。连续对话保留每一句并按顺序处理，不采用“只保留最新一句”的覆盖逻辑。最后一次有效对话或伙伴回复后达到孩子配置的 30/45/60/90/120 秒静默阈值，状态自动回到唤醒待机，不关闭本地唤醒监听。

行为提醒等 `hsc-agent-intervention` 主动事件会先播报提醒，再把已运行的唤醒监听切到连续对话，允许孩子直接回答；切换收音不会取消刚开始的提醒播报。`hsc-privacy-pause` 优先级最高：立即停止录音、取消待处理 ASR、释放设备租约，并锁住自动重开；后续主动提醒不得重新打开麦克风。由于全部监听已经关闭，恢复必须由家长在设备端明确操作，不能伪装成仍可接收孩子语音。

2026-08-30 的隔离 Electron 验收使用真实主进程、preload、renderer、本地 FastAPI、SQLite 和设备租约，仅以合成 WebAudio MediaStream 替代物理麦克风。证据位于 `artifacts/electron-wake-agent-e2e/`：唤醒词跨 renderer 重载持久化、自动待机、主动提醒进入对话、30 秒静默退回、隐私暂停禁止重开均通过；原始媒体文件为 0、云模型调用为 0、活动租约为 0。该证据不等于真实儿童口音唤醒准确率或 Windows 麦克风性能验收，后两项仍需在目标电脑使用知情同意语料测误唤醒、漏唤醒和噪声表现。

## 家庭最低配置与 CPU 回退

本模块的发布基线是 **Windows x64、4 核 8 线程且支持 AVX2 的 CPU、16GB RAM，无独立显卡**。它不继承此前 RTX 4090 验证机的能力承诺：那台设备只是一次安装链路证据，不是产品最低配置。

- 形象是 React/CSS 的 2D 原创角色；没有 3D 数字人、WebGL 模型或 GPU 运行依赖。
- 本地 ASR 使用 Sherpa-ONNX 的 `provider="cpu"` 和 2 个解码线程；浏览器 VAD、降噪、回声消除、声学特征也走 CPU/Web Audio。NPU/集显只能成为可选加速，禁止替代 CPU 路径。
- 不得把 7B 本地 LLM、本地大模型 TTS 或 CUDA 作为学习会话、语音校准或基本计划的隐含前提。自然 TTS 仅能是家长启用的合规云端**文本**合成，或通过许可证审核、能在该 CPU 基线运行的轻量本地引擎。
- 当前 ASR 模型文件、OCR 与 Electron 的实际 RAM 峰值尚未在这台最低配置机上实测；所以“CPU 回退代码存在”不等于“最低配置性能已验收”。

最低配置验证必须在一台干净的 Windows x64 基线机执行，并在同一报告中记录：CPU 型号/AVX2、内存、Windows 版本、是否无独显、模型版本、浏览器/Electron 版本。至少包括以下场景：

| 基准 | 负载与证据 | 必报指标 |
| --- | --- | --- |
| 冷启动与内存 | 启动 Electron + local agent + 已下载 ASR，不打开摄像头 | 首屏、服务就绪、常驻/峰值工作集、进程数。|
| ASR | 10 段儿童授权或等价合成中文音频（短命令、学科词、含噪声），串行和连续 3 段 | 每段时长、转写时延 P50/P95、WER/CER、CPU 峰值、峰值 RAM、失败/重问率。|
| 声音适配 | 3 次短时校准与 10 次本地验证 | 校准时延、内存增量、误提示率；确认不落原始 WAV。|
| TTS | 云端和轻量本地候选各以固定文本 30 次；关闭网络再测 | 首包/完整句 P50/P95、取消到静音时延、CPU/RAM、缓存命中、失败后文本可见。|
| 并发/恢复 | ASR、2D 动画、一次计划调用同时进行；网络超时、强退重启 | UI 帧卡顿、ASR/计划结果、峰值资源、动作仅一次入库、恢复状态。|

在上述数据实际生成之前，任何性能数字都必须标记为“待最低配置实测”，不得从 4090 机器外推。

已提供可重复的 CPU ASR 采样工具：`services/local_agent/scripts/benchmark_voice_cpu.py`。在目标 Windows 机使用隔离目录和合成/单独同意的 WAV 运行 `python services/local_agent/scripts/benchmark_voice_cpu.py --model-dir <models> --work-dir <isolated-output> --wav <test.wav> --runs 3 --concurrency 1`，再以 `--concurrency 2` 运行第二次。它记录实际失败、P50/P95、工作集、CPU 时间和并发数，且明确不保存原始 WAV；没有模型时以失败报告退出，不能作为“性能通过”。

自然语音另有独立的真实链路基准：`services/local_agent/scripts/benchmark_tts_delivery.py`。它只调用已经由 Electron 安全设置启动的本地服务，不接收、读取或输出云端密钥；固定使用非隐私句、丢弃全部 PCM，并记录 30 轮首包/总时延、客户端中断、后续恢复、失败码与工作集。示例：`python services/local_agent/scripts/benchmark_tts_delivery.py --base-url http://127.0.0.1:8765 --session-id <active-test-session> --runs 30 --cancel-every 5 --output <isolated-output>/tts-delivery.json`。仅当自然语音已由家长明确启用、所有普通轮完成且取消后的下一轮恢复成功时，才可把该报告称为真实 TTS 基准；未配置、无网或无同意产生的失败报告都是部署阻塞证据。

## 声音方案结论

当前家长指定的待验收主声为 `longyingtao_v3`（龙应桃，温柔淡定女）。它是第一优先级候选，不是已经开通、已经许可或已经通过 30 轮/30 分钟验收的生产声音；`longanwen_v3`、`longxiaochun_v3`、`longyingmu_v3`、`longanrou_v3` 保留为盲听对照。

2026-08-28 的最小凭据探测表明：token-plan 账户的兼容模型清单包含 `qwen-audio-3.0-tts-plus` 与 `qwen-audio-3.0-realtime-plus`，但 `/audio/speech` 不可用（HTTP 400 `InvalidParameter`，url error）。改用官方 duplex WebSocket 后鉴权和 `task-started` 成功；以 `qwen-audio-3.0-tts-plus`、`longyingtao_v3` 和固定句“现在开始今天的学习计划。”请求合成，返回 `task-failed`、CosyVoice engine 411、零音频，首音不可得，总时延 4590.6ms。故此凭据不能作为当前主声生产通道，不能把模型名称或任务启动当成可播报证据。

同一密钥通过官方 DashScope SDK 的 `SpeechSynthesizer`（将 `base_websocket_api_url` 指向 token-plan 北京工作空间 URL）用 `qwen-audio-3.0-tts-plus` + Qwen 成人女声 `longanlingxin` 成功合成同一固定句：PCM 24kHz/16-bit、102,300 bytes、SDK 首包 638.9ms、总 1067.8ms。它证明 Qwen-Audio-TTS 通道可用，但音色目录不同，不能替代待验收主声 `longyingtao_v3`。`qwen_audio_tts` 只作为显式标记的短期/故障兜底；正式主声仍须单独开通 CosyVoice 音色和许可。

选择原则：只使用原创、已获得商业使用许可的女声；绝不训练或模仿家长、老师、公众人物，且不通过 TTS 上传家庭音/视频。TTS 仅接收回应文字。原始儿童语音默认仅用于本地 ASR，原始介质存储须由家长单独授权。

| 方案 | 自然度/韵律 | 流式首包能力 | 情感 | 离线与隐私 | 成本/许可结论 | 本产品决定 |
| --- | --- | --- | --- | --- | --- | --- |

### 已实现的家长试听与选择流程

家长中心的“自然语音”页提供 HTTPS PCM relay 和阿里云 Model Studio CosyVoice 官方 WebSocket 两种受控配置。CosyVoice 适配器只收 PCM，发送官方 `run-task → continue-task → finish-task` 事件，直连配置只能选择五个审核中的成人主声。家长可播放只读官方样音，并填写盲听表：候选 ID、评分人类别、自然度、中文清晰度、英文/数学、低压提醒、严肃纠错、30 分钟疲劳度、孩子接受度和非身份化备注；记录原子写入本机（模块测试覆盖重启读取，Electron 的保存—重启—读取交互验收仍在进行），不含密钥、孩子语音、试听音频或回答文本。密钥本身通过 Electron `safeStorage` 加密，读取摘要不回显密钥；删除会重启 local agent 并停用云端 TTS。

这是一条真实的候选选择工作流，不是自然声效果的替身：没有可用 relay、账户和许可证时，试听操作应失败且不保存配置；系统音只可作为带标签的临时播报。

共享评测包可通过开发环境显式设置 `HSC_VOICE_EVAL_ROOT=<本机用户目录>/hsc_eval_assets/voice` 后在 Electron 家长页播放官方试听。它读取只读包中的阿里云 CosyVoice 预览和 sherpa-onnx VITS-Melo 预览，但不会把音频复制到学习数据库、孩子档案、TTS 缓存或发布包。实际桌面点击已验证 `longyingtao_v3` 的官方预览可播放、播放中其他候选禁用、结束后恢复。主声评测顺序为 `longyingtao_v3`、`longanwen_v3`、`longxiaochun_v3`、`longyingmu_v3`、`longanrou_v3`；`longanhuan_v3` 限游戏/庆祝，`longhuhu_v3` 仅故事角色，二者无法填入“待评主声”。

盲听表必须为每位候选、每段固定文本记录：自然度、中文清晰度、英文/数学读法、首包和完整句时延、打断恢复、低压提醒、严肃纠错、连续 30 分钟疲劳度、孩子主观接受度。官方预览只覆盖部分听感维度；首包、打断、回复文本的读法仍只能在真实合规云端流中验收。

### 上线门槛（尚未满足）

## 儿童声音适配与边界

`VoiceCalibrationPanel` 提供可选的短时校准，先勾选同意，随后只在浏览器内计算 RMS、过零率和粗粒度频带特征。原始 WAV 不落盘、不上传，校准特征可在界面中删除和重做。它是麦克风质量与“可能不是本人”的提醒，不是身份验证、考勤或一次录音训练大模型：单次按键录音低置信时仍在本机识别，但明确提示孩子确认或改打字；免按键模式的低置信片段不自动执行，转为按键确认或文字入口，避免非本人声音触发学习操作。

校准从单段升级为**三段本地环境样本**：安静靠近、正常坐姿、轻微日常环境声。每段只参与更新 RMS、过零率、粗粒度频带均值和环境离散度；不会保存 WAV、声纹 embedding、可逆录音或跨孩子特征。特征在浏览器 `localStorage` 中按 child ID 隔离，删除会同时清除旧版本键；旧单段特征需重新完成三段校准后才能允许免按键自动提交。这里的“相近/不确定”仅是低风险提示，绝不能用于身份认证、考勤或惩罚。

ASR 当前的 Sherpa 离线解码结果不提供可校准的 token 置信度，因此产品不把音量或频带分数伪称“ASR 置信度”。发送前只有诚实的本地**信号质量门**：过短、过轻/持续噪声、严重削波会要求靠近或远离麦克风后重说，且不发送识别；可发送时仍提示孩子核对转写。`evaluate_voice_capture_resilience.py` 仅接受公开/合成 WAV，在内存中派生确定性 20 dB/10 dB 噪声、远场近似和削波样本；报告不含音频或文本。2026-08-28 用公开 `test_wavs/0.wav` 的五个样本实际跑通本地 CPU 识别，但这不是儿童语料、WER 或 Windows 基线证据。

词表适配应在本地 ASR 解码词典或后处理的家长可编辑学科词表中实施（人名、教材名、知识点），并记录版本；不能将未验证的转写直接当作作业。当前 UI 保留确认和修改路径。

## 主动介入与关系边界

主动提醒只来自已保存的学习会话、待办、已授权的本地观察候选；有冷却时间、十分钟静音和可关闭观察。不得以孤独、成绩或亲情施压；不得请求保密、替代父母/朋友、诱导延长互动或推销。既有安全分类会把即时风险转入可信成人/紧急帮助路径，关系依赖表达会明确说明不能取代真实关系。

## 可观测性与失败策略

`agent_turn` 保存转写、意图、允许动作、执行状态和错误码；`model_call_audit` 记录云文本模型调用，不记录原始音频。TTS 应新增 `voice_playback_audit`（提供方、音色版本、首包/完整时延、取消原因、重试、文字长度，绝不写音频或密钥）后才允许生产启用。网络、超时、模型异常均应回落到已验证的本地意图规则或文本 UI，并告诉用户“没有保存成功/暂时未配置”，不能隐藏 demo fallback。
