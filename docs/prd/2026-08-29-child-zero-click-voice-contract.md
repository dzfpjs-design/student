# 孩子端零点击语音交互契约

日期：2026-08-29  
状态：Frozen product rule

## 1. 不可变原则

孩子在正常使用过程中不需要点击任何 App 功能键。孩子端采用 `Voice-only operation + Display-only surface`：自然语言是唯一控制通道，屏幕只展示智能体形象、字幕、计划、题目、证据、进度、监听状态和执行结果。

按钮即使暂时保留用于研发调试，也不能是完成流程的唯一入口，并且正式孩子模式必须隐藏。家长设置、家长 PIN、设备绑定、紧急物理隐私开关和故障恢复不属于孩子日常流程，可以保留触控。

## 2. 交互状态机

1. 应用随 Windows 孩子账号自动启动；存在未完成会话时自动恢复到原状态。
2. 待机只监听本地唤醒词。孩子说个人唤醒词后进入连续对话。
3. 连续对话中，每个完整语音片段按先后顺序进入队列，不覆盖、不丢弃较早语句。
4. 智能体执行动作后用语音说明结果，并主动提出当前唯一必要的下一问。
5. 连续静默达到家长设定时间后回到唤醒词待机。
6. 智能体可主动提醒并直接进入连续对话；孩子拒绝、说“稍后”或无回应时降低提醒频率。
7. “停”“取消”“我说错了”“再说一遍”“简单一点”“找家长”在所有状态可用。

## 3. 零点击功能矩阵

| 场景 | 必须支持的语音动作 |
|---|---|
| 进入 | 身份确认、开始、继续未完成会话 |
| 签到 | 精力、固定安排、明日考试、确认进入课堂回忆 |
| 课堂回忆 | 连续补充、纠正、删除、确认、不记得、进入作业 |
| 作业 | 口述、拍作业页、确认 OCR、逐项修改/删除、无作业、生成计划 |
| 计划 | 朗读计划、调整顺序/时长、确认开始 |
| 学习 | 开始、暂停、继续、休息、延期、完成并检查、还需订正 |
| 辅导 | 提问、拍题、确认/修正题干、要提示、换种讲法、取消调用 |
| 诊断 | 请求题目、听题/重播、口述答案、提交、下一题、结束 |
| 错题 | 标为错题、说明错因、订正、请求变式、确认掌握 |
| 行为提醒 | 接受、稍后、拒绝、减少同类提醒、纠正误判 |
| 复盘 | 口述完成情况、困难、心情、明日关注点、确认结束 |
| 通用 | 查询进度、隐私暂停、停止播报、取消、撤销、求助家长 |

## 4. 执行规则

- 低风险且可撤销动作可直接执行，例如开始计时、暂停、重播。
- 会写入长期证据、删除内容、结束会话或可能重复收费的动作必须语音复述并确认。
- ASR 或意图置信度不足时只问一个澄清问题，不猜测、不推进状态。
- 工具失败必须语音说明当前数据是否已保存、是否会重复调用以及可说出的恢复命令。
- 原始音视频默认不上传；需要云模型时先使用本地抽取后的最小必要文本或结构化证据。
- 隐私暂停会关闭麦克风，恢复必须依赖家长或物理控制，不能设计成仍在暗中监听“恢复”命令。

## 5. 发布验收

发布验收必须使用真实麦克风、目标 Windows 电脑和真实本地服务，从应用启动走到日报生成。自动化脚本只能注入 ASR 最终文本，不得调用孩子端按钮的 `click()`。

通过条件：

- 两个孩子都能独立完成完整每日流程，孩子点击次数为 0。
- 连续说 10 句时按顺序持久化 10 个 turn，不只保留最新一句。
- 任意阶段说“取消/我说错了”不会误写长期证据。
- 应用重启后恢复会话、待处理确认和语音队列的权威状态。
- 网络中断时，本地唤醒、计划、计时、隐私、暂停和恢复仍可用。
- 摄像头、高拍仪、模型或 TTS 失败时均有语音恢复路径。

## 6. 当前差距

当前已具备唤醒词、连续监听、逐句排队、本地关键命令、基础流程调度和 TTS，但仍有按钮专用路径。主要缺口是首页身份/启动、课堂与作业纠错、OCR 逐字确认、完成核对、诊断、错题整理、复盘和失败恢复的完整语音动作。上述缺口全部关闭并完成目标机零点击实测前，不得宣称孩子端 Voice-only 已完成。
