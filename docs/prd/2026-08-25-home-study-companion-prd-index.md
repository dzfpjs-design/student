日期：2026-08-25  
版本：v0.1  
状态：当前研发入口

## 1. 路线说明

当前项目为家庭自用软件，服务南京一名初三学生和一名四年级学生。系统运行在家庭电脑上，接入摄像头、高拍仪、麦克风和国产模型API；不研发吊坠、定制底座和专用平板，不建设学校端和商业化量产体系。

总体开发周期为14天，2026年8月25日开始，2026年9月7日完成家庭版v0.1目标设备验收。长期教育效果和模型校准在发布后持续验证，不延长两周开发交付时间。

## 3. 阅读顺序

研发开始前依次阅读总体PRD、长期能力与全量功能PRD、实施计划、本地数据设备隐私PRD和每日学习闭环详细PRD。开发AI能力时补充阅读AI知识库PRD和课程知识内化PRD。测试计划从D1开始执行，不等到功能开发结束后再读取。

## 4. 权威顺序

文档冲突时按以下顺序处理：

1. 当前家庭版总体PRD中的产品边界和非目标。
2. 长期能力与全量功能PRD中的完整产品范围、能力分层和完成门槛。
3. 本地数据设备隐私PRD中的权威状态、隐私和持久化要求。
4. 每日学习闭环详细PRD中的业务状态机和用户流程。
5. AI知识库PRD与课程知识内化PRD中的模型、诊断、内容成熟度和策略要求。
6. 测试计划中的发布阻塞标准。
7. 实施计划中的排期和任务拆分。

2026年6月形成的商业硬件PRD仅作为历史设计参考，不覆盖本套文档。

## 7. 已冻结决策

- 产品只服务当前家庭和两个孩子。
- 首版采用家庭电脑，不适配用户自有平板。
- 孩子端交付Windows x64桌面App，采用Electron + React界面和Python本地服务，不依赖浏览器标签页运行。
- 孩子端全部日常流程零点击，语音是唯一控制通道；触控只属于家长设置、紧急隐私和故障恢复。
- 采用现成摄像头和高拍仪，不开发新硬件。
- 原始连续音视频不上传，默认不落盘。
- 通用模型通过适配层接入，不在v0.1训练专用模型。
- 知识库采用课程标准、教材索引、个人证据、策略库和知识图谱。
- 摄像头默认影子模式，行为推断必须支持unknown。
- 两周完成家庭版v0.1开发和目标设备验收。
