# 儿童硬件安全、规格冻结与量产测试 PRD

日期：2026-06-17
来源：五专家设计评审 P0-9、P0-10、P0-12

## 1. 目标

修正硬件规格冲突，建立儿童接触安全矩阵、云台工程验证和量产 DFT/校准闭环。

## 2. 吊坠双方案 stack-up

| 方案 | 尺寸目标 | 电池 | 目标 |
|---|---:|---:|---|
| 小吊牌版 | 约 40 x 36 x 10 mm | 250-350mAh | 轻佩戴、低采样策略、1-2 天 |
| 大校牌版 | 约 38 x 72 x 16 mm | 600-800mAh | 增强版、2-3 天重度策略 |

决策门槛：

- 8-12 岁儿童 7 天佩戴排斥率。
- 上学场景老师/学校接受度访谈。
- 真实策略续航。
- 表面温升。
- 触点脏污后入仓成功率。
- 挂绳安全脱开力。

文档修正：在实测前，不再把单一尺寸写成 v1.0 冻结值。

## 3. 云台工程验证

P0 先用现成二轴/三轴模组验证视角；P1 再决定是否定制三轴。

必须完成：

- CAD 运动包络。
- A4/A3 拍摄几何。
- Roll 轴价值验证。
- 两轴 + 数字横滚校正备选方案。
- FMEA。
- 防夹间隙和堵转力。
- 线束/FPC 寿命。
- 夜间噪声。
- 跌落后回中。
- 隐私区软件限制。

验收：

- 儿童手指阻挡 200ms 内停止或降力。
- 云台动作噪声不显著影响唤醒和语音识别。
- 桌面 A4 纸张检测成功率 >= 90%。

## 4. 儿童硬件安全矩阵

| 风险 | 设备 | 要求 |
|---|---|---|
| 勒颈 | 吊坠挂绳 | 断开式安全扣，定义脱开力 |
| 误吞 | 吊坠/底座小件 | 小零件不可轻易脱落，磁铁固定冗余 |
| 皮肤接触 | 吊坠 | 材料接触安全、汗液、过敏风险评估 |
| 咬咬材料 | 吊坠 | 外壳材料和涂层安全 |
| 烫伤 | 底座/平板/吊坠 | 表面温升限制和过温降级 |
| 电池鼓包 | 平板/吊坠 | 电芯认证、保护板、运输和售后处理 |
| 夹手 | 云台 | 防夹结构、堵转检测、低力矩策略 |
| 声学伤害 | 底座/平板 | TTS/音效最大音量限制 |
| 学校隐私 | 吊坠 | 不联网、不摄像、不实时上传、低敏摘要 |

## 5. 认证策略

中国大陆首发最低关注：

- 平板 CCC。
- 平板/吊坠电池 CCC。
- 电源适配器 CCC。
- Wi-Fi/BLE/UWB SRRC。
- 含锂电运输 UN38.3/MSDS。
- 蜂窝版才纳入进网许可。

认证不等于儿童安全，儿童安全需要单独 DfS 矩阵和测试。

## 6. DFT/产测/校准

| 工站 | 测试 |
|---|---|
| 主板 | 电源、接口、存储、Wi-Fi/BLE、Secure Element |
| 摄像头 | MTF、对焦、畸变、坏点 |
| 麦克风 | 灵敏度、噪声、通道一致性 |
| 扬声器 | 频响、最大音量、失真 |
| 云台 | 回中、限位、堵转、噪声、校准参数写入 |
| 吊坠 | 电池内阻、充电、IMU、麦克风、BLE、触点 |
| 防水 | 抽检或全检策略 |
| 老化 | 充放电、云台循环、温升 |

每台设备必须绑定序列号、校准数据、测试结果和固件版本。
