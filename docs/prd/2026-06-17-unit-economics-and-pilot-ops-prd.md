# 单位经济模型与试点运营 PRD

日期：2026-06-17
来源：五专家设计评审经济性与可运营性问题

## 1. 目标

补齐硬件三件套、云端推理、内容版权、售后、渠道和试点运营成本模型，判断产品是否商业可持续。

## 2. Landed COGS

| 成本项 | 说明 |
|---|---|
| BOM | 平板、底座、吊坠、适配器、包装 |
| 制造费 | 组装、SMT、人工、管理 |
| 测试校准 | 云台、摄像头、麦克风、吊坠、老化 |
| 良率损耗 | DVT/PVT/MP 不同阶段 |
| 认证摊销 | CCC/SRRC/电池/适配器/运输 |
| 物流仓储 | 国内运输、仓储、退换货 |
| 售后预提 | 换新、维修、备件、客服 |
| NRE 摊销 | ID/MD/电子/模具/系统定制 |
| 渠道税费 | 渠道扣点、税费、支付成本 |

## 3. 云端与内容成本

| 成本项 | 计量 |
|---|---|
| ASR/TTS | 每分钟/每家庭/月 |
| LLM 讲题 | 每请求/每 token |
| 报告生成 | 每日报/周报/月报 |
| RAG/向量库 | 存储 + 查询 |
| 内容版权 | 题库、故事、视频、小游戏 |
| 审核/人工复核 | 每条高风险样本 |
| 数据存储 | 热/冷/备份 |

## 4. 收入模型

至少测算三种：

| 模型 | 说明 | 风险 |
|---|---|---|
| 高硬件毛利 + 低订阅 | 首购门槛高 | 获客难 |
| 低硬件毛利 + 高订阅 | 现金流压力 | 续费必须强 |
| 硬件适中 + 分层订阅 | 推荐测算 | 复杂度高 |

## 5. 试点 SOP

规模：20-50 个家庭，周期 4-8 周。

试点前：

- 监护人授权。
- 家庭场景说明。
- 数据留存说明。
- 设备安全检查。
- 客服和紧急联系人准备。

试点中：

- 每日设备健康巡检。
- 每周家长访谈。
- P0 安全事件 24 小时内复盘。
- 高风险 AI 输出人工复核。
- 吊坠学校使用先不进入真实采集。

试点后：

- 留存/删除确认。
- 家庭满意度。
- 孩子使用意愿。
- 学习闭环完成率。
- 设备故障率。
- 云成本/家庭/月。

## 6. 退出标准

| 指标 | 目标 |
|---|---|
| P0 隐私/安全事故 | 0 |
| 7 天活跃 | >= 70% |
| 学习会话完成率 | >= 60% |
| 娱乐到点返回成功率 | >= 90% |
| 家长报告阅读率 | >= 60% |
| 设备 P0 故障 | 0 |
| 云成本 | 不超过预算红线 |
