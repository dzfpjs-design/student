# AI 安全、训练数据与评测 PRD

日期：2026-06-17
来源：五专家设计评审 P0-11

## 1. 目标

让 AI 能力上线前有可复现的评测门槛、合法训练数据链路和成本可控的端云模型策略。

## 2. AI Safety Eval

评测集分层：

| 集合 | 最小规模 | 覆盖 |
|---|---:|---|
| S0 普通学习 | 500 | 讲题、计划、复习、错因 |
| S1 陪伴边界 | 300 | 依恋、保密请求、角色混淆 |
| S2 家长脚本 | 300 | 冲突降温、非羞辱、可执行 |
| S3 儿童风险 | 300 | 欺凌、恐惧、家庭冲突 |
| S4 紧急危机 | 200 | 自伤/他伤/正在危险 |
| S5 对抗越权 | 300 | 要求撒谎、绕过家长规则、诱导上传 |

上线门槛：

- S4 漏判为普通陪伴：0。
- P0 安全用例：100% 通过。
- 家长脚本高风险禁用召回率：100%。
- 讲题事实性错误率低于发布阈值并人工抽检。

## 3. 训练数据合规

数据进入训练前必须有：

- 样本卡。
- 授权链。
- 数据来源。
- 去标识算法版本。
- 第三方儿童声音/图像排除策略。
- 删除/撤回补偿策略。
- dataset manifest。

禁止默认进入训练：

- 学校场景原始音频。
- 第三方儿童声音。
- 家庭冲突原始片段。
- 孩子敏感倾诉全文。
- 未单独授权的语音质量片段。

## 5. TinyML 与底座模型 Benchmark

| 模型 | 指标 |
|---|---|
| 吊坠 TinyML | 模型大小、RAM 峰值、推理延迟、每小时耗电、误报/漏报、摩擦噪声鲁棒性 |
| Audio Recheck | 误唤醒率、AEC 后识别率、电机噪声场景、barge-in P95 |
| Sensitive Scene Filter | Precision/Recall、低光、多人、遮挡、误拒绝率 |
| Desk Detector | A4/A3 检测率、模糊识别、反光、阴影、裁剪准确率 |
| Child Presence | unknown 率、离席识别、误跟随、隐私区拒绝 |

## 6. 学习诊断最小规格

v0.1 使用可解释掌握度模型：

- 初始先验按年级/单元/前测结果。
- 每次练习更新 `mastery_score` 和 `confidence`。
- 正确率、用时、提示次数、独立程度、错因标签进入更新。
- 输出必须包含证据数量和置信度。
- 冷启动时只给低置信建议，不做强结论。

## 7. 成本控制

| 项目 | 策略 |
|---|---|
| 语音意图 | 小模型/本地缓存优先 |
| 讲题 | 先 OCR/题型路由，再选择模型 |
| 报告 | 批处理，夜间生成 |
| 家长脚本 | 模板 + 模型润色 + 安全门 |
| 超预算 | 降级到缓存计划、模板解释、延迟报告 |

每家庭/月必须设置云模型成本预算和告警。
