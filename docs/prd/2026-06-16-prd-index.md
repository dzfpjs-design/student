## 3. v0.1 研发目标

根据五专家评审，原 v0.1 范围过大，已重切为 v0.1a/v0.1b/v0.1c。v0.1 总目标仍是验证“孩子愿意用、系统管得住、学习闭环跑得起来、家长看得懂”，但首轮只承诺可验证薄片，不把三件套硬件量产作为同一阶段阻塞项。

v0.1a 必须打通：

- 专用 Android 学习平板 Agentic Launcher。
- 全局伴随式拟人智能体作为主交互，完成意图理解、上下文整合、主动伴随和跨端资源调度。
- Device Owner / Lock Task / 应用白名单基础控制。
- 学习会话、故事会话、小游戏/视频会话的 App Session 生命周期。
- 云端计划与报告最小闭环。
- 家长端规则、报告、白名单、隐私暂停、数据删除入口。
- 基础数据库、事件、审计和测试体系。

v0.1b 打通底座模拟器或工程样机：设备状态、云台拍题、隐私状态、本地 API、能力租约、本地儿童状态引擎。

v0.1c 打通吊坠模拟事件或工程样机：入仓同步、低敏事件摘要、孩子分享引导。

不进入 v0.1：

- 学校端/老师端触点。
- 开放第三方 App 生态。
- 本地完整大语言模型。
- 连续屏幕录制和连续家庭视频上传。
- 大规模内容商城。
- 多国家多法域合规自动化。
- 真实学校场景吊坠采集。
- 三轴云台量产结构冻结。
- 吊坠量产结构冻结。

## 4. 研发优先级

| 优先级 | 模块 | 原因 |
|---|---|---|
| P0 | Agentic Launcher、App Session、Device Policy、规则执行 | 没有系统边界，产品会退化为普通儿童 App |
| P0 | 学习会话、学习证据、每日计划 | 没有学习闭环，无法证明“家教”价值 |
| P0 | 家长授权、隐私暂停、删除、审计 | 儿童数据产品的信任底座 |
| P0 | 事件和数据库基础表 | 后续测试、报告、AI 调优都依赖它 |
| P1 | 故事/游戏/视频陪伴与收尾 | 建立孩子信任，同时验证边界 |
| P1 | 底座云台拍题与吊坠同步摘要 | 体现软硬件差异化 |
| P1 | 家长脚本化建议 | 从报告走向家庭行为改变 |
| P2 | 内容运营后台、实验平台、训练样本中心 | v1.0 前补齐 |

## 5. 编号规范

需求编号：

- `OVR-*`：总体 PRD
- `AOS-*`：孩子端 Agentic OS
- `VAG-*`：全局伴随式拟人智能体
- `DCK-*`：底座
- `PND-*`：吊坠
- `CLD-*`：云端
- `PAR-*`：家长端
- `DB-*`：数据库
- `EVT-*`：事件
- `QA-*`：测试

事件命名：

- 使用小写蛇形命名。
- 格式：`domain_action_result`。
- 示例：`session_started`、`learning_evidence_created`、`tablet_blocked_launch_attempt`。

验收级别：

- `MUST`：v0.1 阻塞项。
- `SHOULD`：v0.1 推荐项，可在试点前补齐。
- `MAY`：v1.0 或后续增强项。
