# v0.1 范围重切 PRD

日期：2026-06-17
版本：v0.1 reset
来源：五专家设计评审 P0-1

## 1. 目标

把原先过大的 v0.1 拆成 3 个可验证薄片，避免平板、底座、吊坠、云端、家长端、AI 安全和合规同时阻塞。

核心原则：

- v0.1 不追求三件套量产闭环。
- v0.1 只验证“孩子端系统边界 + 学习/娱乐会话 + 家长授权/隐私暂停”是否成立。
- 底座和吊坠先用模拟器或工程样机接入，不作为首轮量产承诺。
- 每个薄片都必须可演示、可测试、可埋点、可回滚。

## 2. 阶段划分

| 阶段 | 周期 | 目标 | 不做 |
|---|---:|---|---|
| v0.1a | 8-12 周 | 专用 Android 平板 Agentic OS、DPC、App Session、学习/娱乐会话、家长授权/删除/隐私暂停 | 真实吊坠、真实底座量产、完整云台、长期画像 |
| v0.1b | 4-8 周 | 底座模拟器/工程样机接入，验证拍题、隐私状态、本地 API、租约和事件 | 吊坠量产、三轴云台定制、完整 HIL |
| v0.1c | 4-8 周 | 吊坠事件模拟/工程样机，验证入仓同步、低风险事件摘要、分享引导 | 学校真实采集试点、训练数据入库 |

## 3. v0.1a 必须交付

| 模块 | MUST 交付 | 验收 |
|---|---|---|
| Agentic Launcher | 开机、Home、异常恢复回到主屏 | 重启后 10 秒内进入 Launcher |
| DPC/Lock Task | 阻止普通桌面、设置、侧载、非授权 App | 攻击性测试通过 |
| App Session | 学习、故事、视频/小游戏、休息统一会话 | 所有内容入口都带 session_id |
| 家长授权 | 分项授权、撤回、隐私暂停、删除请求 | 撤回后功能降级，事件可审计 |
| 学习闭环 | 今日计划、讲题、错题证据、复习建议 | 10 个典型学习脚本跑通 |
| 娱乐边界 | 白名单、倒计时、收尾、回主屏 | 到点后 30 秒内返回主屏 |
| 语音主交互 | 计划查询、开始学习、拍题模拟、隐私暂停 | `voice_turn_id` 贯穿工具调用 |
| 云端最小服务 | 计划、报告草稿、安全门、事件接收 | P0 安全用例 100% 通过 |

## 4. v0.1a 明确不做

- 不接真实学校场景吊坠数据。
- 不承诺三轴云台量产结构。
- 不做本地完整 LLM。
- 不做老师端。
- 不开放第三方 App 生态。
- 不保存原始家庭视频。
- 不把 AI 输出作为心理诊断或惩罚评分。

## 5. v0.1b 底座薄片

目标：

- 验证底座作为隐私网关和硬件能力提供者是否成立。
- 验证实时音视频不上传云端时，底座能否用 Local Child State Engine 输出可用的低敏状态摘要。
- 先使用开发板 + 现成云台/摄像头/麦阵列。
- 平板通过能力租约调用底座。

MUST：

- `GET /dock/status`
- `POST /leases`
- `POST /camera/capture-request`
- `GET /child-state/current`
- `GET /child-state/session-summary`
- `POST /privacy/pause`
- `child_state_event_created`
- `gimbal_mode_changed`
- `camera_privacy_rejected`
- 本地事件缓存与断网补传摘要

验收：

- 隐私暂停后底座拒绝拍题。
- 无有效租约时底座拒绝摄像头/云台调用。
- 原始实时音视频不上云，云端只收到状态摘要。
- 底座离线时平板降级到平板摄像头补拍。

## 6. v0.1c 吊坠薄片

目标：

- 验证“离线低风险线索 -> 回家入仓同步 -> 孩子分享引导”的产品闭环。

MUST：

- 先用事件模拟器，随后接工程样机。
- 事件只包含低敏摘要：时间段、场景、运动、设备状态。
- 入仓同步摘要进入平板。
- 不做学校实时上传。
- 不做长语音转写。

验收：

- 吊坠同步摘要不被用作审问证据。
- 孩子端只做低压力分享引导。
- 家长端报告标注“线索，不是结论”。

## 7. 统一退出标准

| 指标 | v0.1a 退出标准 |
|---|---|
| P0 隐私事故 | 0 |
| 系统控制绕过 | 攻击性测试 100% 阻断 |
| P0 安全用例 | 100% 通过 |
| App Session 覆盖 | 所有内容入口 100% 带 session |
| 家长授权撤回 | 5 秒内前端降级，云端不再处理新增高敏数据 |
| 删除请求 | 可追踪、可重试、可审计 |
| 7 天稳定性 | 无 P0 崩溃或数据错乱 |
| 家庭脚本 | 20 个核心家庭场景跑通 |

## 8. 对既有文档的影响

- `prd-index` 中 v0.1 目标应改为 v0.1a/v0.1b/v0.1c。
- `overall-prd` 的里程碑应把底座/吊坠从 v0.1 必须项降为模拟或工程样机。
- `test-plan` 应增加 v0.1a 攻击性测试和退出标准。
