# 儿童安全处置 Runbook PRD

日期：2026-06-17
来源：五专家设计评审 P0-4

## 1. 目标

为儿童危机表达、自伤、被伤害、虐待线索、家庭冲突和高风险心理表达建立可执行处置剧本。该 Runbook 不替代专业机构、学校或监护人责任。

## 2. 风险分级

| 等级 | 示例 | 系统行为 |
|---|---|---|
| R0 普通压力 | “我不想写作业”“今天好烦” | 共情、休息建议、学习计划调整 |
| R1 情绪困扰 | “我很难过”“我不想去学校” | 低压陪伴，引导家长温和关注 |
| R2 高风险线索 | “有人欺负我”“我很害怕回家” | 停止普通陪伴脚本，通知家长查看，建议线下沟通 |
| R3 紧急风险 | 自伤/他伤具体意图、正在发生危险、虐待明确线索 | 立即升级家长，显示紧急资源建议，记录最小审计 |

## 3. 禁止行为

- 不承诺“我不会告诉家长”。
- 不进行心理诊断。
- 不指责孩子或家长。
- 不让孩子独自承担处置。
- 不把吊坠/摄像头线索当成审问证据。
- 不在高风险场景继续娱乐化陪伴。

## 4. 响应模板

R1：

> “听起来你今天真的有点累。我可以陪你先缓一缓。你不用马上说清楚，我们可以先做一个很小的选择：喝水、休息 5 分钟，或者告诉爸爸妈妈你今天需要一点安静。”

R2：

> “这件事听起来让你不舒服，也可能需要大人帮忙。你不用一个人处理。我会提醒爸爸妈妈用温和的方式来关心你，不会让他们审问你。”

R3：

> “现在安全最重要。请马上去找身边可信的大人，或者让爸爸妈妈马上过来。我会提醒家长立刻关注这件事。”

## 5. 家长通知原则

| 等级 | 通知 | 内容 |
|---|---|---|
| R0 | 不强制 | 进入日报趋势 |
| R1 | 可延迟 | 建议今晚低压沟通 |
| R2 | 及时 | 说明“孩子可能需要关注”，附沟通脚本 |
| R3 | 立即 | 清晰提醒紧急关注，建议联系线下专业/紧急资源 |

家长通知不得包含羞辱性判断，不输出“孩子撒谎”“孩子有心理问题”等标签。

## 6. 人工复核

试点阶段：

- R2/R3 必须进入人工复核队列。
- 复核人员只看最小必要摘要。
- 原始音视频默认不进入人工复核，除非家长明确授权且场景合法。
- 所有复核操作写入审计日志。

## 7. 评测要求

每次模型、提示词、策略包更新必须通过：

- R0/R1 普通压力集合。
- R2 欺凌/恐惧/家庭冲突集合。
- R3 自伤/他伤/正在危险集合。
- 对抗样本：孩子要求保密、让系统撒谎、要求不要告诉家长。

P0：R3 漏判为普通陪伴次数必须为 0。
