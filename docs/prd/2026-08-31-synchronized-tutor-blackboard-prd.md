# 语音同步讲题黑板 PRD

## 1. 用户结果

孩子只需说出问题或把题目放到高拍仪下。Agent 一边用自然声音讲解，一边在同一黑板上写出当前所讲的条件、关键概念、公式、推导和检查问题。孩子不需点击“打开黑板”或“下一步”。

完成标准不是“播放了语音”，而是孩子能借助同步表征理解方法，并继续完成复述、作答或迁移题。

## 2. 讲解协议

Tutor 每轮返回一个持久化输出包：

- `content`：按顺序拼接后的完整口语讲解。
- `blackboard.title`：本轮讲解标题。
- `blackboard.segments[]`：语音段、板书块和建议时长的共同时间线。
- `blocks[]`：`heading`、`text`、`formula`、`steps`、`table`、`relation`、`question`。
- `source`：`model_structured` 或 `local_degraded`，便于质量分析而不向孩子暴露内部细节。

语音口播不读 LaTeX，而读成年龄合适的自然语言；黑板公式使用受限 LaTeX 渲染。

## 3. 运行状态

1. `preparing`：已收到讲解，黑板保持稳定尺寸，暂不写入。
2. `speaking`：从真实首个音频帧或系统语音 `onstart` 开始时间线。
3. `interrupted`：打断语音且取消未来板书定时器，已写内容保留。
4. `completed`：语音与板书完整呈现，继续进入理解检查。
5. `degraded`：模型结构无效或输出被安全策略改写时，由本地从安全口播构建板书。

## 4. 学科表达

- 数学/物理/化学：公式、已知/未知、单位、分步推导、图形关系的文字化表达。
- 语文/英语：句子成分、篇章结构、词义对照、语法变化、证据与结论。
- 历史/道法：时间顺序、因果链、人物/事件/影响表格。
- 地理/生物：系统层级、过程链、条件对比和分类表。

本阶段不伪造手写笔迹或自由绘图。真正的几何作图、坐标曲线和实验图需进入后续受限图形原语组件，不允许模型输出任意 HTML/SVG 代码。

## 5. 安全与失败恢复

- 口播和可见板书分别执行安全检查，不能用板书绕过分层提示和答案泄露策略。
- 拒绝 HTML、外部链接、图片引用和 LaTeX 自定义宏；普通文本交由 React 转义。
- 自然语音失败但系统语音可用时，不发布中间错误事件，黑板继续同步。
- 全部语音不可用时，立即显示完整板书，不让孩子面对空白界面。
- 讲解输出包随 Tutor Turn 保存，页面刷新、Electron 重启和后端重启后可恢复。

## 6. 验收门槛

- 两个年级各选数学、语文/英语、理科/综合学科代表题，检查正确性、年龄适配和板书可读性。
- 真实 Electron 与自然女声环境下测量首音频帧到首块板书的偏差，以及后续段的对应感。
- 验证语音提问、主动讲解、高拍仪题目、打断、语音降级、断网、刷新和重启。
- 在 1366×768、1920×1080 和平板宽度下检查无遮挡、无溢出，长公式、长单词和表格可滚动查看。
