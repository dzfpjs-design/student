# Synthetic electron-builder NSIS template experiment

This directory contains a **synthetic-only** test project. The GitHub Actions job downloads only these four synthetic files at the triggering commit; it does not checkout or run the household application. Every run generates a fresh unrelated appId, NSIS GUID, program directory, data directory and HKCU keys on a disposable GitHub-hosted Windows runner. No family data, credentials, product binary or real product identity are inputs.

The lockfile pins Electron 44.0.0 and electron-builder/app-builder-lib 26.15.3 and their transitive npm packages using integrity hashes. The job uses `npm ci --ignore-scripts --no-audit --no-fund` against the npm registry. Running electron-builder itself still executes the downloaded build tool and downloads its Windows/Electron packaging artifacts; the proposed workflow should be reviewed before being enabled. It uses no external GitHub Actions and requests only `contents: read`.

The test builds v1 and v2 installers using the actual electron-builder NSIS template. Each of four isolated cases creates a fresh v1 install and tests normal upgrade, a one-byte CRC-covered uninstaller mutation, an uninstaller stub independently proven to return 7, and a missing uninstaller. It records the installer's observed exit code, installed program version by app.asar SHA, synthetic registration version, and whether a separate synthetic SQLite file survives unchanged and passes `quick_check`. NSIS modal windows are closed only for direct synthetic uninstaller children; a timeout is **inconclusive** and fails the job. Temporary files, the synthetic profile and the two unique synthetic HKCU keys are cleaned in `finally`, with the hosted VM providing the final isolation boundary.

This experiment tests template behavior for a synthetic per-user install. It cannot prove the house machine's root cause, data safety, production installer equivalence, rollback, or real-device behavior. The workflow is intended for a dedicated branch and is not a release gate.
